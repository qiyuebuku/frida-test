## 任务

### 1. 分类

将每条设定归入以下 5 类之一：

- **power_system**：修炼等级、功法、法术、法宝能力、灵气、修为、特殊能力
- **geography**：地名、地理特征、位置关系、距离、地形、建筑
- **factions**：组织、势力、门派、家族、宗门、帮会
- **rules**：世界硬性规则、软性限制、社会习俗、禁忌、制度
- **misc**：无法归入以上类别的条目

### 2. 去重

识别描述同一设定的不同条目，合并为一条（保留最完整的描述 + 所有出处章节）。

### 3. 标记首次出现

每条设定标注 `first_chapter`（该设定首次揭示的章节编号）。

## 输出格式

请直接输出一个合法的 JSON 对象，不要添加任何 markdown 代码块标记或额外解释：

{
  "power_system": [

      "name": "设定名称",
      "description": "完整描述",
      "first_chapter": "chXXXX",
      "source_chapters": ["chXXXX", "chXXXX"],

  "geography": [...],
  "factions": [...],
  "rules": [...],
  "misc": [...]

- 每条设定的描述要完整、精确，不要过度概括
