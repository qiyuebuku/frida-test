## 任务

检查上述角色列表，找出**不同批次**中实际是同一人的角色。

常见跨批次重复模式：
- 全名 vs 简称（如"李通崖" vs "通崖"，因出场次数不同被分到不同批次）
- 姓名 vs 称号/绰号（如"张真人" vs "张三丰"）
- 不同关系下的称呼（如"师父" vs 具体人名，需结合 identity 判断）
- 同一 identity 描述但不同名字

**注意**：
- 只关注**跨批次**的重复，同批次内的别名已经处理过了
- `keep` 应选出场次数更多的那个名字
- 不确定的标注 `"confidence": "low"`

## 输出格式

请直接输出 JSON，不要添加代码块标记或额外解释：

{
  "cross_batch_aliases": [
    {
      "keep": "保留的正名（出场次数更多的）",
      "merge": "要合并掉的名字",
      "confidence": "high|medium|low",
      "reason": "合并原因"
    }
  ]
}

如果没有发现跨批次重复，返回空列表：
{"cross_batch_aliases": []}
