## 任务

将上述三大信息源融合，使用 Write 工具生成 3 个 Markdown 文件。

**核心原则**：
- **统计 + 语义交叉验证**：如 Python 统计"短句占比 35%"，Claude 分析"战斗场景偏好短句"→ 融合为"战斗场景短句率高于日常场景"
- **弧级差异标注**：如果不同弧的统计有显著差异，在产出中标注"XX 类弧的风格特征"
- **读者验证优先**：高赞段落中使用的写作技巧应在"写作指导"中**优先推荐**
- **可操作**：每个维度都要有"写作指导"——不只是统计数据，要有实用的续写建议
