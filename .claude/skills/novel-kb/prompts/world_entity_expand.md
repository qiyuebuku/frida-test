## 任务

对每个实体执行以下操作：

### 1. 标注重要性

- **high**：世界观核心设定。例如：修炼境界体系、核心地理区域（主角长期活动的区域）、主要势力、基本世界法则。对理解故事背景必不可少。
- **medium**：故事级设定。例如：具体功法/法术、次要地点、支线势力、具体规则。在特定情节中重要。
- **low**：一般提及。例如：仅出现一两次的地名、背景性提及的物品、不影响剧情的小设定。

### 2. 扩写描述

- **high/medium 实体**：将描述扩写到 200-500 字，包含：
  - 核心定义（这是什么）
  - 具体细节（有哪些特征/规则/层次）
  - 在故事中的作用（与主角或主线的关系）
  - 与其他实体的关联（如适用）
  - 演化轨迹（如有变化，按章节标注）
- **low 实体**：保持简要描述（1-3 句），不需要扩写

### 3. 整理来源章节

确保 source_chapters 完整、按章节号排序。

## 输出格式

请直接输出一个合法的 JSON 数组，不要添加任何 markdown 代码块标记或额外解释：

[
  {
    "name": "实体名称",
    "importance": "high|medium|low",
    "description": "扩写后的详细描述",
    "first_chapter": "chXXXX",
    "source_chapters": ["chXXXX", ...],
    "evolution": "演化说明（如有）",
    "related_entities": ["关联实体名1", "关联实体名2"]
  }
]

重要：
- 严格基于输入的实体数据扩写，不要凭空创造新设定
- 扩写时保持与原始描述一致，不要修改设定内容，只做信息补充和结构化
- related_entities 只列出**同类别内**的关联实体名
- 保持 JSON 格式合法，字符串内的引号使用 \" 转义
