你是专业的小说世界观构建师。你的任务是将分类后的设定数据融合为完整的世界观文档。

## 数据来源

**分段设定文件**（使用 Read 工具读取以下文件）：
{segment_files_list}

**角色势力信息**（使用 Read 工具读取）：
`{raw_world_data_path}` 中的 `character_factions` 字段

## 任务

请将上述数据融合为 4 个 Markdown 文件，使用 Write 工具写入以下路径：

### 1. 力量体系：`{world_dir}/power_system.md`

按照以下格式：

```
# 力量体系

## 修炼等级
- 等级名：描述（首次提及：chXXXX）

## 等级限制
每个等级能做什么、不能做什么

## 修炼代价
提升等级需要付出什么

## 能力上限
当前已知的最强存在是什么级别

## 已出现的重要能力/法术
- {能力名}：效果，使用者，首次出现章节
```

### 2. 地理空间：`{world_dir}/geography.md`

```
# 地理空间

## 主要区域/国家
- {区域名}：简述（首次提及：chXXXX）

## 重要城市/地点
- {地点名}：位于哪里，有什么特殊之处（首次提及：chXXXX）

## 空间距离关系
- A 到 B：大约多远/多久的路程

## 已发生关键事件的地点
- {地点}：chXX 发生了什么
```

### 3. 组织势力：`{world_dir}/factions.md`

```
# 组织势力

## {势力名}
- 目标：
- 立场：
- 与其他势力的敌对/合作关系：
- 已知成员：（结合角色势力信息补充）
- 在故事中扮演的角色：
- 首次提及：chXXXX
```

### 4. 规则与限制：`{world_dir}/rules.md`

```
# 世界规则与限制

## 硬性规则（绝对不能违反）
- 规则：描述（依据：chXXXX）

## 软性限制（通常情况下如此，但有例外）
- 限制：描述（例外情况）

## 社会规则/禁忌
- 规则：描述（依据：chXXXX）
```

## 要求

1. **去重合并**：同一设定在多个段中出现时，合并为一条，保留最完整的描述
2. **演化追踪**：如果设定有更新/修正，标注首次和更新的章节
3. **势力成员**：将角色势力信息合并到 factions.md 的"已知成员"字段
4. **章节标注**：每条设定都标注首次出现的章节
5. **如果某个类别没有数据**，仍生成文件，写"（暂无相关信息）"
6. **misc 类条目**：如果 misc 中有条目，尝试归入最合适的类别；实在无法归类的，放入 rules.md 的末尾单独一段

使用 Write 工具写入 4 个文件。
