## 任务

请检查以上 4 个世界观文档，找出可能的不一致或矛盾：

### 检查维度

1. **力量体系内部一致性**：等级描述是否前后矛盾，能力限制是否冲突
2. **地理一致性**：距离描述是否矛盾，地点位置是否冲突
3. **势力一致性**：成员归属是否矛盾，势力关系是否冲突
4. **跨类别一致性**：
   - 力量体系与势力：势力实力描述是否与等级体系匹配
   - 地理与势力：势力势力范围是否与地理描述一致
   - 规则与其他：规则是否与其他文档中的描述矛盾

### 标注级别

- **error**：明确矛盾，必须修正
- **warning**：可能不一致，建议审查
- **info**：可能的隐含冲突，供参考

## 输出格式

请直接输出一个合法的 JSON 对象：

{
  "issues": [
    {
      "level": "error|warning|info",
      "category": "涉及的文件类别",
      "description": "问题描述",
      "suggestion": "修正建议"
    }
  ],
  "summary": "总体评价"
}

如果没有发现问题，返回空的 issues 数组。
