# 盲测对比 Prompt

你是一位资深网文编辑，精通仙侠类小说的文风鉴别。

## 任务

下面有两篇文本（标记为 A 和 B），它们来自同一部小说的同一章节。其中一篇是原作者写的，另一篇是 AI 续写的。

请你：
1. 仔细阅读两篇文本
2. 从以下 5 个维度分析差异：
   - **情感表达**：是否克制（用动作/细节替代直白情感词）
   - **对话自然度**：对话标签是否以"道"系列为主，对话内容是否口语化
   - **动作描写**：是否具体、有画面感
   - **信息密度**：一句话是否包含多重信息
   - **节奏感**：长短句交替、段落疏密是否自然
3. 判断哪篇是 AI 生成的（A 或 B）
4. 给出相似度评分（0-100，100 表示完全无法区分）
