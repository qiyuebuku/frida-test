# 🧠 一、核心目标（你到底在做什么）

你要实现的是：

```text
当前事件 → 找历史相似事件 → 看当时市场反应 → 决定现在是否交易
```

本质是：

> ✅ **用市场的“记忆”替代主观判断**

# 🧩 二、系统结构（可落地版本）

---

## 📦 你需要多一张“历史事件库”

```json
{
  "event_id": "evt_202401_ai_policy",

  "text": "国家出台政策支持AI算力发展",

  "embedding": "...",

  "tags": ["AI", "算力", "政策"],

  },

  "market_result": {

```

---

👉 注意：

**最重要的不是 embedding，而是：**

```text
market_result（市场真实反馈）
```

# ⚙️ 三、完整流程（一步一步能写代码）

---

## 🧩 Step 1：构建“事件向量”

不要直接用原新闻！

👉 用你 schema 里的：

```text
title + summary + industries + event_type
```

拼接：

```python
event_text = f"""
{event.title}
{event.summary}
行业: {event.entities.industries}
类型: {event.event_type}
"""
```

---

## 🧩 Step 2：计算相似事件（TopK）

```python
similar_events = topK(
    query_embedding,
    historical_event_embeddings,
    k=5
)
```

---

👉 输出类似：

```text
[
  evt_202401_ai_policy (0.92),
  evt_202308_compute (0.89),
  evt_202210_cloud (0.83)
]
```

---

## 🧩 Step 3：过滤（非常关键！）

---

### ❌ 过滤掉：

```python
if similarity < 0.8:
    丢弃

if 时间太久（>2年）:
    降权

if event_type 不一致:
    丢弃
```

---

👉 你要保证：

> **“相似”是真的“同一类市场行为”**

---

## 🧩 Step 4：提取“历史收益分布”

---

```python
returns_1d = [e.market_result["1d_return"] for e in similar_events]
returns_3d = [e.market_result["3d_return"] for e in similar_events]
```

---

👉 得到：

```text
1日收益: [2.1, 1.8, 2.5]
3日收益: [6.5, 5.2, 4.8]
```

---

## 🧩 Step 5：计算“期望收益 + 胜率”

---

```python
import numpy as np

expected_return = np.mean(returns_3d)
win_rate = sum(r > 0 for r in returns_3d) / len(returns_3d)
```

---

👉 输出：

```text
expected_return = 5.5%
win_rate = 100%
```

---

# 🚨 四、决策逻辑（最关键）

---

## ❗不要直接用相似度做决策

错误：

```python
similarity > 0.9 → 买 ❌
```

---

## ✅ 正确方式：用“历史表现”决策

---

### 🎯 推荐规则：

```python
if (
    expected_return > 2%
    and win_rate > 0.7
    and len(similar_events) >= 3
):
    buy
else:
    reject
```

---

👉 本质是：

> **“历史上这种情况赚钱吗？”**

---

# 🧠 五、基金选择（历史驱动）

---

```python
funds = [e.best_fund for e in similar_events]

most_common = Counter(funds).most_common(1)
```

```python
fund_score[fund] += event_return
```

# ⚠️ 六、3个致命坑（一定要避）

---

## ❌ 坑1：语义像，但市场逻辑不同

例子：

```text
“AI政策”
“AI公司裁员”
```

embedding 可能很像，但：

👉 一个涨，一个跌

---

✅ 解决：

```python
必须过滤 event_type
```

---

---

## ❌ 坑2：样本太少

```text
只有1~2个历史事件 → 完全不可信
```

---

✅ 解决：

```python
len(similar_events) < 3 → 不交易
```

---

---

## ❌ 坑3：市场环境不同

```text
牛市 vs 熊市
```

---

✅ 解决（非常重要）：

加入“市场状态过滤”

```python
if 当前市场 != 历史市场:
    降权
```
