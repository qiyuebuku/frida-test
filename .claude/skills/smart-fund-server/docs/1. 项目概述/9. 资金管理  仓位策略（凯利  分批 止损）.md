# 🧮 三、基础仓位（凯利简化版）

---

## ❗不要直接用标准凯利公式

经典凯利：

```text
f = p - (1-p)/b
```

👉 问题：

* 你很难准确知道 p（胜率）
* 会导致仓位过大

---

## ✅ 用“经验凯利”（推荐）

你可以用：

```python
base_position = score * 0.3
```

---

👉 举例：

```text
score = 0.8 → 仓位 = 24%
score = 0.6 → 仓位 = 18%
```

---

👉 再加一个上限：

```python
max_position_per_trade = 0.3  # 单笔最多30%
```

---

# 🧱 四、分批建仓（非常重要）

---

## ❗不要一次性买入

改成：

```text
分 2~3 次买
```

---

## ✅ 推荐模型（简单好用）

---

### 🎯 2段式建仓（最实用）

```text
第一笔：60%
第二笔：40%（确认后加）
```

---

### 🧠 触发第二笔：

```python
if 买入后上涨 > 1% and 资金流持续:
    加仓
```

---

👉 好处：

* 避免买在假突破
* 确认趋势再加码

---

# 🛑 五、止损机制（必须有）

---

## ❗基金不能像股票一样高频止损

👉 所以要“宽止损 + 结构止损”

---

## ✅ 推荐两种止损

---

### 1️⃣ 固定止损（底线）

```python
if 浮亏 < -3%:
    全部卖出
```

---

👉 基金波动小，-3%已经不小了

---

---

### 2️⃣ 事件失效止损（更重要）

```python
if 事件流不再发酵:
    卖出
```

---

👉 判断：

* 新闻减少
* 资金流出
* 情绪下降

---

---

# 📈 六、加仓机制（赚钱关键）

---

## ❗原则：

> ❌ 不要在亏损时加仓
> ✅ 只在“验证正确”时加仓

---

## ✅ 推荐规则：

```python
if 盈利 > 2% and 事件流仍在增强:
    加仓 20%
```

---

---

## ❗限制：

```python
最多加仓1次
```

---

👉 防止：

> 一路加仓 → 顶部接盘

---

# 🧮 八、完整策略（可以直接写代码）

---

```python
def decide_position(score):

    base = score * 0.3
    return min(base, 0.3)


def should_add_position(profit, event_strength):

    return profit > 0.02 and event_strength > 0.7


def should_stop_loss(loss, event_active):

    if loss < -0.03:
        return True

    if not event_active:
        return True

    return False
```

# 📊 九、完整交易流程（强烈建议你照这个实现）

---

```text
1. AI给出信号（score）
2. 计算基础仓位
3. 买入第一笔（60%）
4. 观察（1~2小时 / 次日）
5. 若验证正确 → 加仓
6. 若失败 → 止损
7. 事件结束 → 止盈离场
```
