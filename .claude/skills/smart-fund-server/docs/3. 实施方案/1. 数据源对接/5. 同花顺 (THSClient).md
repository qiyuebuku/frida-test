### 问财 (iwencai) — 已实现

**API**：`POST https://www.iwencai.com/customized/chart/get-robot-data`

**认证流程**（完全脱离手机自动运行）：
```
同花顺App启动 → Zygisk Hook读取WebView Cookie DB → 提取v+sess_tk等
  → POST /api/auth/hexin-v 上报到服务端 → 存储到ft_config数据库
  → THSClient.get_iwencai_query() 从DB读取token → 构造Cookie请求问财API
```

**方法**：

| 方法 | 说明 | 频率限制 |
|------|------|---------|
| `get_iwencai_query(question)` | 自然语言查询，返回原始响应 | ≥60秒/次 |
| `get_iwencai_stocks(question)` | 提取结构化股票列表 | 同上 |

**Token 管理**：
- **自动上报**：Hook 每 30 分钟从 Cookie DB 读取并上报（CookieDbWatcher）
- **缓存刷新**：服务端收到新 token 时自动刷新 THSClient 内存缓存
- **有效期**：~31 天（与 sess_tk JWT 同步）
- **Token 失效恢复**：删除 App 的 Cookie DB → 重启 App → 自动获取全新 token

**⚠️ 使用限制**：
- 请求间隔必须 ≥60 秒，否则触发验证码锁定 token（不可逆）
- 适合低频查询场景（如每日盘前选股、事件驱动查询）
- 不适合高频轮询
