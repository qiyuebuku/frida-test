### 9.2 雪球（已逆向破解）

#### 反爬机制分析

雪球使用**阿里云 WAF** + **httpOnly cookie** 双重防护：

1. 首页返回 WAF JS 挑战页（`aliyun_waf` meta 标签 + `/u21pn7x6/r8lw5pzu/psk8uqfi` 脚本）
2. 浏览器执行 JS 后获得 httpOnly cookie：**`xq_a_token`**、`xqat`、`xq_r_token`、`acw_tc`
3. `document.cookie` 拿不到 httpOnly cookie → 纯浏览器 eval 无法导出 token
4. WAF 在网络层注入 `md5__1038` 签名参数（不影响纯 HTTP 请求，只要有正确 cookie 即可）

#### 破解方案

**两步走：** Playwright `context.cookies()` 获取 httpOnly cookie + `curl_cffi` 模拟 Chrome TLS 指纹

```python
# Step 1: 通过 spy 服务获取 httpOnly cookie（新增 /api/spy/cookies 端点）
cookies = httpx.get("http://server:8900/api/spy/cookies?domain=xueqiu").json()["cookies"]
cookie_str = "; ".join(f'{c["name"]}={c["value"]}' for c in cookies)

# Step 2: 用 curl_cffi 模拟 Chrome TLS 指纹请求
from curl_cffi import requests as cf
session = cf.Session(impersonate="chrome120")
r = session.get("https://xueqiu.com/hot_event/list.json?count=10",
                headers={"Cookie": cookie_str, "Referer": "https://xueqiu.com/"})
```

**前提条件：** spy 浏览器服务需先访问过 `xueqiu.com`（WAF JS 验证），之后 cookie 在 session 有效期内（约数小时）可复用。

## 建表

```sql
CREATE TABLE IF NOT EXISTS ft_sentiment (
    id          SERIAL PRIMARY KEY,
    data_type   VARCHAR(32) NOT NULL,
    data        JSONB NOT NULL,
    trade_date  DATE NOT NULL,
    captured_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_ft_sentiment_type_date ON ft_sentiment(data_type, trade_date);
```

`data_type` 取值：`guba_popularity` / `guba_posts` / `xueqiu_hot_topics` / `xueqiu_hot_stocks` / `xueqiu_live_news` / `limit_pool`
