# 自选标的数据采集

本模块包含两部分：
1. **全市场数据源**（北向资金/板块资金流/龙虎榜）→ `ft_market_flow`
2. **自选标的定向采集**（个股行情/资金流/基金净值/持仓/规模...）→ `ft_watchlist_data`

---

## 一、架构概览

```
ft_collection_state
  ├── aggregator=fund_flow         ← 全市场源
  │     northbound / sector_flow_sina / dragon_tiger_em / dragon_tiger_ths
  │
  └── aggregator=watchlist         ← 自选标的
        007380 / 159915 / sh600036 / ...

                    ↓ 采集数据写入 ↓

ft_market_flow      ← 全市场数据（northbound/sector_flow/dragon_tiger）
ft_watchlist_data   ← 自选标的数据（所有维度统一存储）
```

---

## 二、ft_watchlist_data 表设计

```sql
CREATE TABLE IF NOT EXISTS ft_watchlist_data (
    id          SERIAL PRIMARY KEY,
    code        VARCHAR(16) NOT NULL,       -- 股票/基金代码
    data_type   VARCHAR(32) NOT NULL,       -- 数据维度
    trade_date  DATE,                       -- 数据日期（快照类为采集日）
    data        JSONB NOT NULL,             -- 数据内容
    created_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE UNIQUE INDEX IF NOT EXISTS idx_watchlist_data_unique
    ON ft_watchlist_data(code, data_type, trade_date);
CREATE INDEX IF NOT EXISTS idx_watchlist_data_code
    ON ft_watchlist_data(code, data_type);
```

### 场内 ETF/LOF 维度

场内基金同时采集**基金维度 + 个股维度**：
- 基金维度：nav, realtime, holdings, scale, ...
- 个股维度：stock_flow, quote, minute_data, kline

判断场内/场外：代码以 `15`（深交所 ETF）、`51`（上交所 ETF）、`16`（LOF）开头为场内。

### QDII 基金关联维度

| `us_quote` | 美股实时行情 | Tencent | `get_us_quote(code)` | 纳斯达克/标普关联 |
| `hk_us_kline` | 港美股 K 线 | Tencent | `get_hk_us_kline(code, period)` | 日/周/月前复权 |
| `global_index` | 全球指数行情 | Sina | `get_global_index()` | 道琼斯/纳斯达克/恒生/... |

## 六、采集流程

所有数据源统一在 `FundFlowAggregator` 中。

### FundFlowAggregator.sources

```python
sources = [
    # ── 全市场源 → ft_market_flow ──
    SourceDef("northbound",       ..., 600,   normalize_northbound),
    SourceDef("sector_flow_sina", ..., 1800,  normalize_sector_flow_sina),
    SourceDef("dragon_tiger_em",  ..., 21600, normalize_dragon_tiger_em),
    SourceDef("dragon_tiger_ths", ..., 21600, normalize_dragon_tiger_ths),
    # ── watchlist 驱动 → ft_watchlist_data ──
    SourceDef("watchlist_data",   ..., 1800,  normalize_watchlist_data),
]
```

### watchlist_data 源逻辑

```python
async def fetch_watchlist_data(cp):
    """遍历 watchlist，按 type 采集对应维度数据"""
    items = checkpoint_store.list_all("watchlist")
    results = []

    for item in items:
        if not item.get("enabled"):
            continue

        code = item["source_name"]
        config = item.get("config", {})
        item_type = config.get("type", "fund")
        dimensions = get_dimensions_for_type(item_type, code, config)

        # 并发采集该标的的所有维度
        for dim in dimensions:
            data = await fetch_dimension(code, dim)
            if data:
                results.append({"code": code, "data_type": dim, "data": data})

        # 更新采集状态
        checkpoint_store.update_success("watchlist", code, {
            "mode": "incremental", "newest_time": now,
        }, saved_count=len(results))

    return results
```

| 信号 | 含义 |

| dragon_tiger | ~3 交易日 | 盘后数据 |
