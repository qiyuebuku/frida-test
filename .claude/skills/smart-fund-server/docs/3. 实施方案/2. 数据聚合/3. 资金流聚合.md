# 资金流聚合

**Service：** `src/domain/aggregation/fund_flow.py`
**Task 入口：** `src/interfaces/tasks/aggregator_tasks.py` → `agg_fund_flow`（队列 `agg_fund_flow`，Schedule 每 5 分钟）
**优先级：** P0 — 事件验证的"确认信号"
**目标表：** ft_market_flow
**状态：** ✅ 已上线（5 个源，4 种 data_type）

---

## 职责

聚合北向资金、板块资金流、个股主力资金三个维度的数据，统一格式写入 `ft_market_flow`。

资金流是事件的"确认信号" — 一个利好消息如果没有资金跟进，说明市场不认可，不应交易。

---

## 采集频率

| 维度 | 频率 | 说明 |
|------|------|------|
| 北向资金 | 盘中 10 分钟 | 最高频，"聪明钱"方向 |
| 板块资金流 | 盘中 30 分钟 | 验证事件板块是否有资金跟进 |
| 个股主力资金 | 盘中 30 分钟 | 重仓股主力动向 |
| 龙虎榜 | 盘后 1 次 | 机构/游资席位 |

---

## 关键信号

| 信号 | 阈值 | 含义 |
|------|------|------|
| 北向单日净流入 > 100 亿 | 强烈看多 | 加仓信号 |
| 北向连续 3 日净流出 | 警惕回调 | 风控信号 |
| 板块资金流入 + 事件利好 | 信号增强 | 买入确认 |
| 板块资金流出 + 事件利好 | 信号减弱 | 暂不交易 |

## 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS ft_market_flow (
    id          SERIAL PRIMARY KEY,
    data_type   VARCHAR(32) NOT NULL,   -- northbound/sector_flow/stock_flow/dragon_tiger
    trade_date  DATE NOT NULL,
    data        JSONB NOT NULL,
    created_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_ft_market_flow_type_date ON ft_market_flow(data_type, trade_date);
```

## 空数据过滤

`_save()` 会自动过滤 `data` 字段为空（空 dict / 空 list / None）的记录，避免入库垃圾数据：

```python
def _save(self, items):
    for item in items:
        data = item.get("data")
        if data is None or (isinstance(data, (dict, list, str)) and len(data) == 0):
            continue  # 跳过空数据
        ...
```

对于 `stock_flow`，还额外检测 `today` 字段全 0 的情况（指数或非交易日返回空数据），直接跳过 normalize。
