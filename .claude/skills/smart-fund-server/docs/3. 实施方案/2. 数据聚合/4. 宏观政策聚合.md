# 宏观政策聚合

**Service：** `src/domain/aggregation/macro.py`
**Task 入口：** `src/interfaces/tasks/aggregator_tasks.py` → `agg_macro`（队列 `agg_macro`，Schedule 每 1 小时）
**优先级：** P1 — 决策方向约束
**目标表：** ft_macro_indicators
**状态：** 待实现

---

## 职责

聚合宏观经济指标（CPI/PMI/GDP/M2 等）和货币政策数据（LPR/Shibor/汇率），统一格式写入 `ft_macro_indicators`。

宏观数据更新频率低（月度/季度），但决定了"可投方向"的大前提。

---

## 数据源

| 指标 | 客户端 | 方法 | 频率 |
|------|--------|------|------|
| CPI | EM | `get_macro_cpi` | 月度 |
| PPI | EM | `get_macro_ppi` | 月度 |
| PMI | EM | `get_macro_pmi` | 月度 |
| GDP | EM | `get_macro_gdp` | 季度 |
| M2 货币供应 | EM | `get_macro_m2` | 月度 |
| 人民币贷款 | EM | `get_macro_rmb_loan` | 月度 |
| 外汇储备 | EM | `get_macro_forex_reserve` | 月度 |
| 固定资产投资 | EM | `get_macro_fai` | 月度 |
| FDI | EM | `get_macro_fdi` | 月度 |
| LPR | PBOC | `get_currency_data("shibor")` → lpr 字段 | 月度 |
| Shibor | PBOC | `get_currency_data("shibor")` → shibor 字段 | 日度 |
| USD/CNY 汇率 | PBOC | `get_currency_data("usdcny")` | 日度 |

所有 EM 宏观方法还支持增量：`get_macro_since(indicator, since_date)`。

---

## 统一输出格式

```python
{
    "indicator": str,       # cpi/ppi/pmi/gdp/m2/rmb_loan/forex_reserve/fai/fdi/lpr/shibor/usdcny
    "period": str,          # 2026-02（月度）或 2026-Q1（季度）或 2026-03-21（日度）
    "value": float,         # 指标值
    "unit": str,            # %/亿元/亿美元
    "prev_value": float,    # 上期值（用于计算环比）
    "source": str,          # eastmoney/pboc
    "published_at": str,    # 数据发布日期
}
```

---

## 对决策的影响

| 指标 | 信号 | 影响 |
|------|------|------|
| CPI 上行 | 通胀预期 | 利空消费基金，利多周期基金 |
| PMI > 50 | 经济扩张 | 利多成长/周期基金 |
| M2 增速加快 | 流动性宽松 | 利多权益类基金 |
| LPR 下调 | 降息 | 利多成长基金，利空银行基金 |
| Shibor 隔夜 > 2.5% | 资金面偏紧 | 短期风险偏好下降 |
| 人民币贬值 > 1%/月 | 汇率风险 | 减持 QDII 基金 |

## 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS ft_macro_indicators (
    id              SERIAL PRIMARY KEY,
    indicator       VARCHAR(32) NOT NULL,
    period          VARCHAR(16) NOT NULL,
    value           FLOAT NOT NULL,
    unit            VARCHAR(16) DEFAULT '',
    prev_value      FLOAT,
    source          VARCHAR(32) DEFAULT '',
    published_at    DATE,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(indicator, period, source)
);

CREATE INDEX IF NOT EXISTS idx_ft_macro_ind_period ON ft_macro_indicators(indicator, period);
```
