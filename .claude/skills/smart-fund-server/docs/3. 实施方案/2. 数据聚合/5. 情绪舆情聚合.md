# 情绪舆情聚合

**Service：** `src/domain/aggregation/sentiment.py`
**Task 入口：** `src/interfaces/tasks/aggregator_tasks.py` → `agg_sentiment`（队列 `agg_sentiment`，Schedule 每 15 分钟）
**优先级：** P1 — 风控辅助
**目标表：** ft_sentiment
**状态：** 待实现

---

## 职责

聚合股吧热度、雪球话题/热股、涨停统计、热门股排行等情绪指标，统一格式写入 `ft_sentiment`。

情绪数据反映市场"温度"。板块被过度讨论、情绪过热时是风险信号而非机会。

---

## 数据源

| 数据 | 客户端 | 方法 | 频率 |
|------|--------|------|------|
| 股吧人气排行 | EM | `get_guba_popularity` | 盘中 30 分钟 |
| 个股股吧帖子 | EM | `get_guba_posts` / `get_guba_posts_since` | 盘中 30 分钟 |
| 涨停/跌停统计 | THS | `get_limit_pool` | 盘后 1 次 |
| 问财选股 | THS | `get_iwencai_query` | 按需（≥60 秒间隔） |
| 雪球热门话题 | Xueqiu | `get_hot_topics` / `get_hot_topics_since` | 盘中 30 分钟 |
| 雪球热股排行 | Xueqiu | `get_hot_stocks` | 盘中 30 分钟 |
| 腾讯热门股 | Tencent | `get_hot_stocks` | 盘中 30 分钟 |
| 个股所属板块 | Tencent | `get_stock_plates` | 按需 |

## 统一输出格式

```python
{
    "data_type": str,       # guba_popularity/guba_posts/limit_pool/xueqiu_hot_topics/...
    "trade_date": str,      # YYYY-MM-DD
    "data": dict | list,    # JSONB，结构因 data_type 而异
    "captured_at": str,     # ISO 8601
}
```

### data_type 枚举

| data_type | 数据内容 |
|-----------|---------|
| `guba_popularity` | 股吧人气排行榜 |
| `guba_posts` | 个股股吧帖子列表 |
| `limit_pool` | 涨停/跌停统计 + 涨停原因分布 |
| `xueqiu_hot_topics` | 雪球热门话题 |
| `xueqiu_hot_stocks` | 雪球热股排行 |
| `tencent_hot_stocks` | 腾讯热门股（5分/1时/1日/1周） |

---

## 情绪信号

| 信号 | 判断逻辑 | 用途 |
|------|---------|------|
| 板块过热 | 雪球话题讨论数 > 200 + 股吧相关帖子激增 | 降低该板块事件权重 |
| 涨停/跌停比 | 涨停数 / (涨停数 + 跌停数) | 市场整体情绪温度 |
| 涨停原因集中 | 某原因涨停数 > 总涨停 30% | 当日市场主线 |
| 热股重叠 | 雪球热股 ∩ 腾讯热股 | 高关注度个股（可能过热） |

## 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS ft_sentiment (
    id          SERIAL PRIMARY KEY,
    data_type   VARCHAR(32) NOT NULL,
    trade_date  DATE NOT NULL,
    data        JSONB NOT NULL,
    captured_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_ft_sentiment_type_date ON ft_sentiment(data_type, trade_date);
```
