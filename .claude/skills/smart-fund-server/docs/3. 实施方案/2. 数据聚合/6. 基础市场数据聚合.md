### ft_market_cache 表特点

与其他聚合表不同，`ft_market_cache` 是 **覆盖写入的 KV 缓存**：

| 特征 | 其他表（ft_news 等） | ft_market_cache |
|---|---|---|
| 写入模式 | 追加（INSERT） | 覆盖（UPSERT by data_type） |
| 唯一约束 | fingerprint | `data_type` UNIQUE |
| 保留策略 | 永久保留历史 | 只保留最新值 |
| TTL | 无（DB 不过期） | 每条有 `expires_at`，业务层查询时检查 |
| 用途 | 历史回溯 + 事件抽取 | 实时快照查询 |

业务层使用示例：
```python
# 查最新大盘状态，不请求外部 API
row = db.query("""
    SELECT data FROM ft_market_cache
    WHERE data_type='market_overview' AND expires_at > NOW()
""")
```

## 职责

聚合基金净值/持仓、指数行情、个股估值、港美股、期货/外汇等基础市场数据，为交易执行和仓位控制提供数据支撑。

这是系统的"地基" — 没有净值无法计算收益，没有持仓无法将事件映射到基金。
