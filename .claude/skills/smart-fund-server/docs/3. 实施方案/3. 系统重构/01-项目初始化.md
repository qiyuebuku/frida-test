# Step 1：项目初始化

**目标**：搭建新项目骨架，配置开发环境，为代码平移做好准备。
**性质**：纯新增，不动现有代码。
**风险**：无

---

## 1. 依赖管理

```bash
cat > pyproject.toml << 'EOF'
[project]
name = "smart-fund-server"
version = "2.0.0"
description = "智能基金服务 — 数据聚合 + 交易决策 + 任务执行"
requires-python = ">=3.11"
dependencies = [
    "fastapi>=0.100",
    "uvicorn[standard]",
    "psycopg2-binary",
    "httpx",
    "jettask-python",
    "apscheduler",
]

[project.optional-dependencies]
dev = ["pytest", "pytest-asyncio", "httpx"]
EOF
```

## 2. 环境配置

```bash
cat > .env.example << 'EOF'
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=jettask
DB_USER=jettask
DB_PASSWORD=changeme
REDIS_URL=redis://localhost:6379/0
SERVER_HOST=0.0.0.0
SERVER_PORT=8900
SERVICE_BASE_URL=http://127.0.0.1:8900
OCR_URL=http://127.0.0.1:5002/glmocr/parse
EOF
```

## 3. .gitignore 补充

```
__pycache__/
*.pyc
.env
*.egg-info/
.pytest_cache/
```

## 4. 建目录骨架

```bash
# 四层 + common
mkdir -p src/interfaces/api/routes src/interfaces/api/middleware
mkdir -p src/interfaces/tasks src/interfaces/cli
mkdir -p src/application/services src/application/orchestrators
mkdir -p src/domain/aggregation src/domain/trading src/domain/task/handlers
mkdir -p src/infrastructure/config src/infrastructure/clients src/infrastructure/db
mkdir -p src/infrastructure/tools src/infrastructure/tmux
mkdir -p src/common

# __init__.py
find src -type d -exec sh -c 'touch "$1/__init__.py"' _ {} \;
```

## 5. 验证

```bash
# 骨架不影响现有代码
python main.py   # 正常启动

git add -A && git commit -m "refactor: 项目初始化，搭建 src/ 四层骨架"
```
