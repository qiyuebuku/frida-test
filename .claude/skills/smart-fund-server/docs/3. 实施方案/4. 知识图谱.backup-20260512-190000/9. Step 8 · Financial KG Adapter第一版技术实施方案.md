## 0. 一句话说清楚

Step 8 实现金融 Adapter 第一版，跑通事件驱动投研最小闭环：

```text
新闻 / 公告 / 政策 / 市场信号 / L1回写事件
  -> event / policy
  -> concept / industry
  -> stock
  -> fund holding
  -> fund exposure
```

金融 Adapter 只负责把金融 source records 翻译成平台协议，不自己建表，不绕过 Compiler，也不直接读取具体业务表。

## 4. 第一版关系

必须实现：

| relation_type | 方向 | 默认来源 |
|---|---|---|
| `belongs_to` | stock -> industry / concept | 结构化成分表 |
| `holds` | fund -> stock | 基金持仓 |
| `mentions` | event/policy -> entity | 文本提及 |
| `affects` | event/policy -> entity | 文本明确影响或 L1 事件 |
| `related_to` | entity -> entity | 弱相关候选 |

第一版可只定义不完整实现：

```text
benefits_from
hurt_by
upstream_of
downstream_of
alias_of
causal_hint
```

消费限制必须写入 `ConsumptionRule`。

## 5. Source Mapping

### 5.1 stock_basics

输入：

```text
structured_record
```

必填：

```text
code
name
exchange
```

输出：

- stock node。
- alias。
- external_id。
- structured evidence。

### 5.2 industry_components / concept_components

必填：

```text
taxonomy
component_name/code
member_stock_code
```

输出：

- industry/concept node。
- stock ref。
- belongs_to edge。

### 5.3 fund_holdings

必填：

```text
fund_code
stock_code
report_date
```

输出：

- fund node。
- stock ref。
- holds edge。
- valid_from / valid_to。

### 5.4 policy_news

必填：

```text
source_id
title or text
published_at
```

输出：

- event/policy node。
- mentions edge。
- affects candidate edge。
- text evidence。

### 5.5 news_articles

业务方从 `ft_news` 投影成标准 source record。

必填：

```text
source_id
title or text
published_at
```

输出：

- event node。
- mentions edge。
- affects candidate edge。
- text evidence。

金融文本语义抽取由 `FinancialNewsExtractionStrategy` 承担；Notebook 只做 source mapping 和 compile 调用。

### 5.6 derived_signal

业务方从以下源表投影：

```text
ft_market_flow
ft_market_cache
ft_sentiment
ft_macro_indicators
```

必填：

```text
target_ref
signal_type
observed_at
value
```

输出：

- signal/event node。
- mentions 或 related_to edge。
- structured/rule evidence。

第一版默认不调用 AI。

### 5.7 l1_events

必填：

```text
event_id
event_type
event_time
evidence_refs
```

输出：

- event node。
- mentions。
- affects candidate。

说明：

`l1_events` 是 L1 运行后的回写输入，不是 KG 冷启动输入。KG 冷启动不能依赖 `ft_events`。

### 5.8 feedback_records

必填：

```text
target_type
target_ref
action
reason
```

输出：

- alias 修正。
- relation 状态调整。
- confidence 调整。
- rejected evidence。

## 6. 金融置信和消费策略

第一版规则：

| 来源 | 默认 status | 消费 |
|---|---|---|
| 股票、基金、行业、概念结构化数据 | active | hard |
| 基金持仓 | active | hard，但受报告期约束 |
| 新闻提及 | active/candidate | retrieval/explanation |
| 文本影响 | candidate | explanation/scoring candidate |
| LLM 推断 | review_required/candidate | retrieval/explanation |
| 人工确认 | active | hard/scoring |
| 人工否定 | deprecated | 不消费 |

硬约束：

- `related_to` 不能进入 hard score。
- `causal_hint` 不能触发交易。
- `alias_of` 默认 review_required。
- active edge 必须有 evidence。
