# T0-4 · 查询链路最小验证

> **任务定位**：验证 GraphRAG 不只是能索引，而且至少能完成最小查询闭环。**

---

## 1. 任务目标

状态：`进行中`

最低目标：

1. `community reports` 至少一次成功生成
2. `Global Search` 至少一条成功查询
3. `Local Search` 至少一条成功查询

---

## 2. 这一步验证什么

这一步验证的是：

- GraphRAG 查询链路是否成立
- query engine 是否能消费前面产物
- 返回结果是否可读

这一步不验证：

- 金融结果质量
- 最终 prompt 效果
- 大规模数据下性能

当前已完成的预检：

- 默认 GraphRAG workflow 已成功生成 `community_reports`。
- Global 查询已成功返回中文要点。
- Local 查询已成功返回关系链路解释。
- Basic 查询已成功返回基于 embedding 的相关内容。
- Local 查询已确认使用长 prompt 文件上下文策略，Claude JSONL 中可见 `Read` 工具调用。
- DRIFT 查询能启动并调用真实 embedding，但默认链路较重，暂不纳入第一阶段通过标准。

---

## 3. 完成标准

只有满足下面条件才算完成：

1. 至少得到一条真实 Global 查询结果
2. 至少得到一条真实 Local 查询结果
3. 查询结果能回链到实体、边或文本证据
4. BYOG 最小样例下也能复现上述查询链路

---

## 4. 当前前置依赖

本任务开始前必须先满足：

- `T0-2 GraphRAG completion 对接验证` 完成
- `T0-3 BYOG最小样例验证` 完成

当前说明：

- `T0-2` 已完成。
- 默认 GraphRAG workflow 的查询链路已跑通。
- 由于 `T0-3 BYOG最小样例验证` 尚未完成，本任务不能标记为完全完成，只能标记为 `进行中`。
