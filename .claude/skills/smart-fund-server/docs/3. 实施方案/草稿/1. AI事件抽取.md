# P0：AI 事件抽取

**优先级：** P0
**依赖：** ft_news 表有数据（财联社/政策采集完成后）
**产出：** `ft_events` 表 + `ft_event_streams` 表中有结构化事件数据

---

## 目标

将 ft_news 中的原始新闻/政策，通过 Claude Haiku 抽取为结构化事件，并聚合为事件流。这是整个系统的"大脑"——将非结构化文本转为可交易的信号。

---

## 实施步骤

### Step 1：建表

```sql
CREATE TABLE IF NOT EXISTS ft_events (
    id              SERIAL PRIMARY KEY,
    event_type      VARCHAR(32) NOT NULL,
    event_subtype   VARCHAR(32),
    title           TEXT NOT NULL,
    summary         TEXT,
    entities        JSONB,
    impact          JSONB,
    sentiment       FLOAT,
    novelty         FLOAT,
    certainty       FLOAT,
    market_reaction JSONB,              -- 后续回填
    source_news_ids INTEGER[],
    fingerprint     VARCHAR(64) UNIQUE,
    embedding       VECTOR(1536),       -- 后续扩展
    event_time      DATE,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS ft_event_streams (
    id          SERIAL PRIMARY KEY,
    topic       TEXT NOT NULL,
    industries  TEXT[],
    event_ids   INTEGER[],
    trend       JSONB,
    sentiment   FLOAT,
    is_active   BOOLEAN DEFAULT TRUE,
    updated_at  TIMESTAMPTZ DEFAULT NOW(),
    created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

## Prompt 设计

见 [总体方案 - 第七章](./1.%20总体方案.md#七ai-事件抽取-prompt)

**关键设计决策：**
- 使用 Claude Haiku（成本低、速度快、JSON 输出稳定）
- 批量处理：每次 5-10 条新闻拼成一个 prompt
- 强制 JSON schema：枚举值严格限定，减少后处理成本
- novelty 评估：AI 判断 + 数据库查重（近 3 天同 fingerprint）双重保障

---

## 成本估算

- 财联社日均 300 条 → 分 30 批 → 30 次 Haiku 调用
- 每次 ~2000 input tokens + ~500 output tokens
- 日成本：~$0.03（Haiku $0.25/1M input, $1.25/1M output）
- 月成本：~$0.6
