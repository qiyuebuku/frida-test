# P1：事件反馈回填

**优先级：** P1
**依赖：** ft_events 有数据 + 资金流采集已运行
**产出：** ft_events.market_reaction 字段被回填，支持历史类比和策略复盘

---

## 目标

事件入库后，每天盘后回填该事件对应行业板块的市场反应（T+1/T+3 涨跌幅、成交量变化、北向资金）。用于：
1. 判断消息是否已被市场消化
2. 历史类比交易
3. 策略复盘

---

## 实施步骤

### Step 1：实现回填任务

```python
@router.task(queue="fund_event_backfill", max_retries=2)
async def backfill_event_reaction(ctx: TaskContext) -> dict:
    """
    盘后扫描近 3 天事件，回填 market_reaction

    逻辑：
    1. 查询 ft_events 中 event_time 在近 3 天且 market_reaction 为 NULL 的事件
    2. 根据 entities.industries 找到对应板块
    3. 用 SinaClient.get_sector_ranking 获取板块涨跌幅
    4. 用 EastmoneyClient.get_northbound_recent 获取北向资金
    5. UPDATE ft_events SET market_reaction = {...}
    """
    ...
```

回填的 market_reaction 结构：

```json
{
  "sector_change_1d": 2.3,
  "sector_change_3d": 5.1,
  "sector_volume_change": 1.4,
  "north_flow_1d": 85.2,
  "reaction_delay_minutes": null
}
```

### Step 2：配置定时调度

```python
Schedule(scheduler_id="backfill_event_reaction", queue="fund_event_backfill",
         cron_expression="30 15 * * 1-5", description="事件市场反应回填（盘后）")
```

- [ ] 手动插入测试事件（已知行业），触发回填
- [ ] 检查 market_reaction 字段被正确填充
