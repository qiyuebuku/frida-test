我不给你讲虚的，直接给你一套**可以落地 + 可扩展 + 适合AI抽取的 schema 设计方案**👇

---

# 🧠 一、核心设计原则（先统一思想）

你这个 schema 必须满足 4 个目标：

### ✅ 1. 可结构化（方便查询 & 决策）

→ 不能只是摘要文本

### ✅ 2. 可演化（事件会持续发酵）

→ 一条新闻 ≠ 一个事件

### ✅ 3. 可量化（用于打分）

→ 必须有“强度 / 情绪 / 置信度”

### ✅ 4. 可关联（行业 / 基金 / 时间）

→ 为交易服务

---

# 🧩 二、推荐的三层结构（重点）

不要只设计一个表，你至少要 3 层：

```id="7i9w8m"
News（原始新闻） → Event（事件） → EventStream（事件流）
```

---

# 📰 1️⃣ News（原始数据层）

这是“事实层”，尽量不加工：

```json id="8bnc1u"
{
  "id": "news_001",
  "title": "国家发改委：加快推进算力基础设施建设",
  "content": "...",
  "source": "财联社",
  "published_at": "2026-03-17 09:12:00",
  "url": "...",
  "tags": ["算力", "政策"]
}
```

👉 这层不要动，保证“可回溯”

---

# ⚡ 2️⃣ Event（核心！AI抽取层）

👉 一条新闻 → 0~N 个事件

这是你最关键的 schema 👇

---

## ✅ 标准 Event Schema（推荐版）

```json id="d39gcf"

```

# 🧨 三、字段解释（哪些是“必须做对的”）

我挑重点讲👇

---

## 🔥 1. event_type（极其关键）

建议你固定枚举：

```id="8m7j8l"
policy        政策
macro         宏观
industry      行业
company       公司
capital       资金
rumor         传闻
```

👉 后面决策权重会用到

---

## 🔥 2. impact（交易核心）

```json id="k3j0kz"
{
  "direction": "positive / negative / neutral",
  "strength": 0~1,
  "scope": "market / industry / company",
  "duration": "short / mid / long"
}
```

👉 这是你打分模型的输入

---

## 🔥 3. novelty（新颖度）

👉 判断：

> “这个信息市场是否已经知道？”

例子：

* 首次发布政策 → 0.9
* 老新闻复读 → 0.2

---

## 🔥 4. certainty（确定性）

👉 区分：

* 官媒 → 0.9
* 小道消息 → 0.3

---

## 🔥 5. entities（用于映射）

这是你后面：

```id="zt9s2k"
事件 → 行业 → 基金
```

的桥梁

---

# 🌊 3️⃣ EventStream（事件流层）

👉 多个 Event 聚合成一个“主线”

```json id="j4k6lx"
{
  "stream_id": "stream_ai_compute_001",

  "topic": "AI算力政策",

  "events": [
    "evt_001",
    "evt_002"
  ],

  "trend": {
    "strength": 0.9,
    "momentum": "increasing",
    "duration_days": 3
  },

  "sentiment": 0.8,

  "updated_at": "2026-03-17 14:30:00"
}
```

---

👉 这个东西非常重要：

> **交易不是看“单条新闻”，而是看“事件是否在发酵”**

# ⚙️ 五、进阶优化（拉开差距）

---

## 🚀 1. 加一个“市场反应字段”（很关键）

```json id="u0cl0p"
"market_reaction": {
  "price_change": null,
  "volume_change": null,
  "delay_minutes": null
}
```

👉 用来判断：

> “消息是否已经被市场消化”

---

## 🚀 2. 事件指纹（去重）

```id="n0k1y7"
hash(title + 核心实体)
```

👉 防止重复新闻污染系统

---

## 🚀 3. embedding（你已经在做的话更好）

👉 用于：

* 事件聚类
* 相似事件检索
