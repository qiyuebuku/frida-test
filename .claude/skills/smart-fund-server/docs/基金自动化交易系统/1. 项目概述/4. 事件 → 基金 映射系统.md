# ⚙️ 四、核心算法（不用 embedding 的映射逻辑）

## 🧩 Step 1：事件 → 行业（规则匹配）

用两种方式：

### ✅ 方式1：直接用你 schema 里的字段

```json
"entities": {
  "industries": ["AI", "算力"]
}
```

👉 直接匹配行业表

---

### ✅ 方式2：关键词匹配（兜底）

```python
def match_industry(event, industry_table):
    scores = {}

    for industry in industry_table:
        score = 0
        for kw in industry["keywords"]:
            if kw in event["title"] or kw in event["summary"]:
                score += 1

        if score > 0:
            scores[industry["industry_id"]] = score

    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```

---

👉 输出：

```json
["ai_compute", "cloud"]
```

## 🧩 Step 4：指数 → 基金（筛选）

这里非常关键👇

---

### 🎯 基金筛选规则（强烈建议）

```python
def pick_fund(funds):
    return sorted(
        funds,
        key=lambda f: (
            -f["liquidity"],        # 流动性优先
            f["fee"],               # 费率低优先
            f["tracking_error"]     # 跟踪误差小
        )
    )[0]
```

---

👉 原则：

* 优先 ETF（流动性好）
* C类基金只做补充
* 不碰冷门基金
