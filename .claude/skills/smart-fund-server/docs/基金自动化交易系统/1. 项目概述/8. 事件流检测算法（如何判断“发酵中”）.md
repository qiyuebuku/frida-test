# 🧠 一、先统一定义：什么叫“发酵中”？

不是“有很多新闻”，而是：

```text
事件热度在持续上升 + 资金开始跟随 + 市场还没完全兑现
```

👉 三个核心信号：

1. **信息密度在上升**
2. **情绪在强化**
3. **市场在逐步反应（但没走完）**

---

# 🧩 二、整体模型（你可以直接照这个做）

```text
事件流强度 = 
  新闻密度 × 0.4 +
  情绪强度 × 0.2 +
  增长速度 × 0.2 +
  资金确认 × 0.2
```

---

👉 然后判断：

```text
if 强度高 + 增长中 → 发酵中
if 强度高 + 增长停止 → 已高潮（别买）
if 强度低 → 无效事件
```

# 🧱 Step 1：构建“事件流”（聚类）

你前面已经有 Event 了，这里要做：

```text
把“同一主题”的事件聚合成一个流
```

---

## 👉 方法（不用embedding版本）

用规则：

```python
def same_event_stream(e1, e2):
    if e1.event_type != e2.event_type:
        return False

    if 共同行业交集 > 0:
        return True

    if 标题关键词重叠:
        return True

    return False
```

---

👉 形成：

```text
[AI算力政策流]
  ├─ 新闻1
  ├─ 新闻2
  ├─ 新闻3
```

---

# 🧱 Step 2：计算“新闻密度”（热度）

---

## 📊 定义：

```python
news_density = 最近N小时内事件数量
```

---

👉 推荐：

```python
density_1h = 最近1小时
density_6h = 最近6小时
density_24h = 最近24小时
```

---

👉 判断：

```python
if density_1h > density_6h / 6:
    说明在加速
```

---

# 🧱 Step 3：计算“增长速度”（核心）

---

## 📈 增速（最关键指标）

```python
growth_rate = density_1h / (density_6h / 6 + 1e-6)
```

---

👉 解读：

* > 1 → 在加速（发酵）
* ≈1 → 稳定
* <1 → 降温

---

---

## 🔥 更强版本（斜率）

```python
slope = density_1h - density_6h / 6
```

# 🧱 Step 4：情绪强化

## 📊 来自你的 event.sentiment

```python
sentiment_score = 平均(event.sentiment)
```

---

👉 再加一个：

---

👉 判断：

```python
if sentiment > 0.6 and positive_ratio > 0.7:
```

# 🧱 Step 5：资金确认（非常关键）

---

## 📊 接入：

* 行业资金流
* ETF资金

```python
if 行业资金净流入:
```

---

👉 这一步是：

> ❗防止“媒体热，但资金不买”

# 🧱 Step 6：合成“事件流强度”

---

```python
event_stream_score = (
    normalize(news_density) * 0.4 +
    normalize(sentiment_score) * 0.2 +
```

# 🚨 四、最关键：阶段判断（避免追高）

---

## 🎯 你必须区分 3 个阶段：

---

### 🟢 1. 发酵初期（可以买）

```text

增长：高
资金：刚开始流入
```

👉 特征：

```python

```

---

---

### 🟡 2. 发酵中期（最优）

```text

增长：持续
资金：持续流入
```

👉 最佳买点

---

---

### 🔴 3. 高潮期（禁止买）

```text
密度：极高
增长：下降
资金：开始流出
```

---

👉 判断：

```python
if density 很高 and growth_rate < 1:
    禁止买
```

```python
    if stream.growth_rate < 1.2:
        return False

        return False

    if not stream.capital_inflow:
```
