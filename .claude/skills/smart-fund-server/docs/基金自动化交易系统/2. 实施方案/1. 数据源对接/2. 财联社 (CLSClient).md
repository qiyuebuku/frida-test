# P0：财联社快讯采集

**优先级：** P0（最高）
**状态：** ✅ 客户端已完成 (`services/clients/cls.py`)

---

## 目标

财联社是 A 股最快的中文快讯源（盘中延迟 < 1 分钟），是事件驱动系统的核心原料。

---

## 客户端：CLSClient

**文件：** `services/clients/cls.py`
**运行验证：** `python -m services.clients.cls`

### 接口信息（已验证）

**地址：** `https://www.cls.cn/nodeapi/telegraphList`
**方法：** GET
**无需认证。**

| 参数 | 说明 |
|------|------|
| `app` | 固定 `CailianpressWeb` |
| `os` | 固定 `web` |
| `sv` | 固定 `8.4.6` |
| `rn` | 返回条数（默认 20，最大 50） |
| `refresh_type` | 固定 `1` |
| `order` | 固定 `1` |
| `lastTime` | **增量游标**：传入上一页最后一条的 `ctime`，返回更早的数据 |

### 返回字段

每条快讯包含以下关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 文章 ID |
| `title` | string | 标题 |
| `content` | string | 完整正文（快讯本身就短，content = brief） |
| `brief` | string | 摘要（与 content 基本相同） |
| `ctime` | int | 发布时间（Unix 时间戳） |
| `level` | string | 重要性：`"B"` = 重要，`"C"` = 普通 |
| `bold` | int | 是否加粗（1 = 重点新闻） |
| `reading_num` | int | 阅读量 |
| `subjects` | array | 主题标签：`[{subject_name, plate_id, ...}]` |
| `stock_list` | array | 关联个股：`[{name, StockID, RiseRange, last, ...}]` |
| `shareurl` | string | 分享链接 |
| `author` | string | 来源（如"新华社"、"央视新闻"） |

### 客户端方法

```python
# 基本采集：获取最新 N 条
items = await client.get_telegraph_list(rn=20)

# 翻页：获取 last_time 之前的数据
items = await client.get_telegraph_list(rn=20, last_time=1773804064)

# 增量采集：获取 since_ctime 之后的所有新数据（自动翻页）
new_items = await client.get_telegraph_since(since_ctime=1773804064)
```

### httpx 注意事项

| 问题 | 原因 | 解决 |
|------|------|------|
| 返回 HTML 而非 JSON | `follow_redirects=True` 导致 302 到 HTML 页面 | 设置 `follow_redirects=False` |
| 返回空内容 | 继承了 `BaseClient` 的同花顺 Referer | 覆盖 `__init__`，使用干净的 httpx 客户端 |
| 偶发 302 | 缺少 `Accept: */*` header | 请求时显式带上 |
