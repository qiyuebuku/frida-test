## 返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 公告标题 |
| `content` | string | 完整正文（列表页为空，需调用 `get_content(url)` 获取，不截断） |
| `source` | string | 来源标识 |
| `level` | string | 政策级别（中央/国务院/部委） |
| `url` | string | 详情页完整链接 |
| `published_at` | string | 发布日期（YYYY-MM-DD） |
| `source_name` | string | 来源中文名称 |

## 客户端方法

```python
# 只获取列表（不含正文）
items = await client.get_announcements("gov", limit=10)

# 获取列表 + 自动填充每条的正文（并发请求详情页）
items = await client.get_announcements("gov", limit=10, fetch_content=True)

# 所有栏目
items = await client.get_announcements("gov", limit=10)            # 政府网
items = await client.get_announcements("ndrc", limit=10)           # 发改委·新闻发布
items = await client.get_announcements("ndrc_decree", limit=10)    # 发改委·发改委令
items = await client.get_announcements("ndrc_notice", limit=10)    # 发改委·通知
items = await client.get_announcements("ndrc_plan", limit=10)      # 发改委·规划文件
items = await client.get_announcements("csrc", limit=10)           # 证监会·要闻
items = await client.get_announcements("csrc_interpret", limit=10) # 证监会·政策解读
items = await client.get_announcements("csrc_press", limit=10)     # 证监会·新闻发布会
items = await client.get_announcements("miit", limit=10)           # 工信部·司局动态
items = await client.get_announcements("miit_policy", limit=10)    # 工信部·政策文件

# 增量采集（支持 fetch_content）
new_items = await client.get_announcements_since("gov", since_date="2026-03-01")

# 单独获取某条的完整正文
content = await client.get_content(url)
```

**fetch_content 说明：**
- `fetch_content=False`（默认）：只返回列表概览，content 字段为空，速度快
- `fetch_content=True`：自动并发请求每条的详情页获取正文（最多 5 并发），速度较慢
- 正文提取会按网站匹配正文区域（政府网 `pages_content`、发改委 `TRS_Editor`、证监会 `detail-news`、工信部 `ccontent`），不匹配时 fallback 全文
- 客户端层不截断正文，数据清洗由后续层处理

## 各来源接口详情

### 政府网 (gov)

- **接口：** `https://www.gov.cn/pushinfo/v150203/`（HTML）

### 发改委 (ndrc / ndrc_decree / ndrc_notice / ndrc_plan)

| 栏目 | URL | 内容 |
|------|-----|------|
| 新闻发布 | `/xwdt/xwfb/` | 新闻、会议、调价 |
| 发改委令 | `/xxgk/zcfb/fzggwl/` | 管理办法、规定 |
| 通知 | `/xxgk/zcfb/tz/` | 产业政策、扶持政策、实施意见 |
| 规划文件 | `/xxgk/zcfb/ghxwj/` | 产业规划、管理办法、标准 |

以上四个栏目 HTML 结构相同，共用 `_parse_ndrc` 解析器。
