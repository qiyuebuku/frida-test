## 方法清单

### 基础市场 & 资金流（已有）

| 方法 | 数据 | 域名 |
|------|------|------|
| `get_indices_realtime` | 主要指数实时行情 | push2.eastmoney.com |
| `get_index_kline` | 指数/ETF K线 | push2his.eastmoney.com |
| `get_index_capital_flow_daily` | 指数当日资金流向 | push2.eastmoney.com |
| `get_northbound_recent` | 北向资金近N日 | datacenter-web.eastmoney.com |
| `get_margin_recent` | 融资融券余额 | datacenter-web.eastmoney.com |
| `get_capital_flow` | 资金流向汇总 | push2his.eastmoney.com |
| `_get_market_capital_flow` | 大盘资金流向 | push2his.eastmoney.com |
| `_get_northbound_flow` | 北向资金流向 | push2his.eastmoney.com |
| `_get_northbound_deal` | 北向交易明细 | push2his.eastmoney.com |
| `get_stock_valuation_history` | 个股估值历史 | datacenter-web.eastmoney.com |
| `get_stock_financial` | 个股财务数据 | datacenter-web.eastmoney.com |
| `get_dragon_tiger` | 龙虎榜 | datacenter-web.eastmoney.com |
| `get_yesterday_limit_performance` | 昨日涨停今日表现 | push2ex.eastmoney.com |
| `get_stock_kline` | 个股K线 | push2his.eastmoney.com |
| `get_stock_capital_flow` | 个股资金流 | push2his.eastmoney.com |
| `get_stock_changes` | 盘中异动 | push2ex.eastmoney.com |
| `search_fund` | 基金搜索 | fundsuggest.eastmoney.com |

### 宏观经济指标（新增）

| 方法 | 数据 | reportName |
|------|------|-----------|
| `get_macro_indicator` | 通用宏观查询 | 任意 reportName |

| `get_macro_ppi` | PPI 工业生产者出厂价格 | RPT_ECONOMY_PPI |

| `get_macro_gdp` | GDP | RPT_ECONOMY_GDP |
| `get_macro_money_supply` | M2 货币供应量 | RPT_ECONOMY_CURRENCY_SUPPLY |
| `get_macro_rmb_loan` | 人民币贷款 | RPT_ECONOMY_RMB_LOAN |
| `get_macro_forex_reserve` | 外汇储备 | RPT_ECONOMY_GOLD_CURRENCY |
