# 资金流聚合

**Service：** `services/aggregators/fund_flow.py`
**Task 入口：** `tasks/aggregator_tasks.py` → `agg_fund_flow`（队列 `agg_fund_flow`，Schedule 每 5 分钟）
**优先级：** P0 — 事件验证的"确认信号"
**目标表：** ft_market_flow
**状态：** 待实现

---

## 职责

聚合北向资金、板块资金流、个股主力资金三个维度的数据，统一格式写入 `ft_market_flow`。

资金流是事件的"确认信号" — 一个利好消息如果没有资金跟进，说明市场不认可，不应交易。

---

## 数据源

| 维度 | 客户端 | 方法 | 说明 |
|------|--------|------|------|
| **北向资金** | EM | `get_northbound_recent` / `get_northbound_realtime` | 沪深港通净流入 |
| **板块资金流（概念）** | EM | `get_sector_fund_flow` | 概念/行业板块净流入 |
| **板块资金流（补充）** | Sina | `get_sector_money_flow` | 含超大/大/中/小单分项 |
| **个股主力资金** | Tencent | `get_stock_fund_flow` | 今日+分钟趋势+5日+历史（独有） |
| **盘中异动** | EM | `get_market_activity` | 快速拉升/跳水等异动 |
| **龙虎榜** | EM + THS | `get_dragon_tiger` / `get_ths_dragon_tiger` | 机构/游资席位 |

---

## 统一输出格式

```python
{
    "data_type": str,       # northbound / sector_flow / stock_flow / dragon_tiger
    "trade_date": str,      # YYYY-MM-DD
    "data": dict,           # JSONB，结构因 data_type 而异
    "captured_at": str,     # ISO 8601
}
```

### data 字段结构

**northbound（北向资金）：**
```python
{"net_flow": 8523000000, "sh_flow": 5200000000, "sz_flow": 3323000000}
```

**sector_flow（板块资金流）：**
```python
{"name": "人工智能", "net_amount": 2584659897, "big_in": ..., "big_out": ..., "source": "eastmoney"}
```

**stock_flow（个股主力资金）：**
```python
{"code": "sh600519", "main_net_in": -358304092, "main_in_rate": "27%", "history": [...]}
```

## 采集频率

| 维度 | 频率 | 说明 |
|------|------|------|
| 北向资金 | 盘中 10 分钟 | 最高频，"聪明钱"方向 |
| 板块资金流 | 盘中 30 分钟 | 验证事件板块是否有资金跟进 |
| 个股主力资金 | 盘中 30 分钟 | 重仓股主力动向 |
| 龙虎榜 | 盘后 1 次 | 机构/游资席位 |

---

## 关键信号

| 信号 | 阈值 | 含义 |
|------|------|------|
| 北向单日净流入 > 100 亿 | 强烈看多 | 加仓信号 |
| 北向连续 3 日净流出 | 警惕回调 | 风控信号 |
| 板块资金流入 + 事件利好 | 信号增强 | 买入确认 |
| 板块资金流出 + 事件利好 | 信号减弱 | 暂不交易 |

## 建表 DDL

```sql
CREATE TABLE IF NOT EXISTS ft_market_flow (
    id          SERIAL PRIMARY KEY,
    data_type   VARCHAR(32) NOT NULL,   -- northbound/sector_flow/stock_flow/dragon_tiger
    trade_date  DATE NOT NULL,
    data        JSONB NOT NULL,
    captured_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_ft_market_flow_type_date ON ft_market_flow(data_type, trade_date);
```
