# 基础市场数据聚合

**Service：** `services/aggregators/market.py`
**Task 入口：** `tasks/aggregator_tasks.py` → `agg_market`（队列 `agg_market`，Schedule 每 1 分钟）
**优先级：** P1 — 交易执行的基础设施
**目标表：** ft_cache / ft_market_cache（已有）
**状态：** 部分已有（AggregatorClient），待扩展

---

## 职责

聚合基金净值/持仓、指数行情、个股估值、港美股、期货/外汇等基础市场数据，为交易执行和仓位控制提供数据支撑。

这是系统的"地基" — 没有净值无法计算收益，没有持仓无法将事件映射到基金。

---

## 数据源

| 数据 | 客户端 | 方法 | 说明 |
|------|--------|------|------|
| 基金净值 | THS + Sina | `get_fund_nav_history` / `get_fund_nav` | 双源互补 |
| 基金持仓 | THS | `get_fund_positions` | 重仓股→行业→事件映射 |
| 基金经理/详情 | THS | `get_fund_manager` / `get_fund_detail` | 基金画像 |
| A 股指数 | EM + Sina | `get_index_*` / `get_realtime_quotes` | 上证/深证/创业板/沪深300 |
| A 股个股 | Tencent + Sina | `get_stock_quote` / `get_realtime_quotes` | 批量行情 |
| 个股估值 | Tencent | `get_stock_quote`(PE/PB) / `get_industry_rank` | 估值+行业对比 |
| A 股 K 线 | Sina | `get_kline` | 5/15/30/60/240 分钟 |
| A 股分时 | Tencent | `get_minute_data` | 逐分钟 价格+量+额 |
| 港股行情 | Tencent | `get_hk_quote` | QDII 基金关联 |
| 美股行情 | Tencent | `get_us_quote` | QDII 基金关联 |
| 港美股 K 线 | Tencent | `get_hk_us_kline` | 日/周/月 |
| 全球指数 | Sina | `get_global_index` | 道琼斯/纳斯达克/标普/恒生/台北 |
| 国内期货 | Sina | `get_futures` | 上海金/铜/原油/白银/铁矿石 |
| 国际期货 | Tencent | `get_intl_futures` | 纽约金/银/原油/天然气/铜/大豆/玉米/小麦 |
| 外汇 | Sina | `get_forex` | 美元/欧元/日元/英镑/港币 |
| 汇率趋势 | PBOC | `get_currency_data("usdcny")` | 中间价+均线+信号 |
| 板块涨跌 | Sina | `get_sector_ranking` | 概念/行业板块排行 |
| 个股所属板块 | Tencent | `get_stock_plates` | 行业+概念+地域映射 |

## 已有雏形

现有 `services/clients/aggregator.py` 中的 3 个方法属于本聚合的雏形：

| 方法 | 功能 |
|------|------|
| `get_market_overview` | 大盘总览（指数+北向+龙虎榜+异动） |
| `get_market_environment` | 市场环境（指数趋势+板块分化+资金流向+信号） |
| `get_holdings_valuation` | 持仓估值（基金重仓股 PE/PB） |

迁入 `services/aggregators/market.py` 后扩展港美股/期货/外汇/分时等能力。

## 核心函数

```python
# services/aggregators/market.py

async def run():
    """task 入口：串行采集指数/全球/期货/外汇/板块等市场数据"""

# 已有（从 AggregatorClient 迁入）
async def get_market_overview() -> dict:
    """大盘总览"""
async def get_market_environment() -> dict:
    """市场环境分析"""

    """基金重仓股估值"""

# 新增
async def get_fund_snapshot(fund_code: str) -> dict:
    """基金快照（净值+持仓+经理）"""
async def get_global_markets() -> dict:
    """全球市场（A股指数+港股+美股+全球指数+期货+外汇）"""
async def get_sector_overview() -> dict:
    """板块概览（涨跌排行+资金流向）"""

    """个股详情（行情+估值+行业排名+所属板块+分时）"""
```
