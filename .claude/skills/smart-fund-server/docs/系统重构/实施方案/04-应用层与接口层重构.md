**目标**：引入 AppService 应用层，瘦化 router 为纯参数校验，补全 common 模块和 middleware，实现单向依赖。

## 1. 创建 AppService

从 router 中提取业务逻辑，每个领域一个 AppService：

### QueryService（从 fund_query / market / strategy 提取）

```python
# src/application/services/query_service.py
class QueryService:
    @staticmethod
    async def get_fund_snapshot(code: str) -> dict:
        """基金快照（原 fund_query router 中组合多个 client 调用的逻辑）"""

    @staticmethod
    async def get_market_overview() -> dict:
        """大盘总览（原 market router 逻辑）"""

    @staticmethod
    async def get_strategy_signals(fund_code: str) -> dict:
        """策略信号（原 strategy router 逻辑）"""
```

### AggregationService（从 news router 提取）

```python
# src/application/services/aggregation_service.py
class AggregationService:
    @staticmethod
    async def query_news(**filters) -> list:
        """查询已聚合新闻"""

    @staticmethod
    async def replay(domain: str, start: str, end: str) -> list:
        """历史重放"""
```

### TradeService（从 trade router 提取）

```python
# src/application/services/trade_service.py
class TradeService:
    @staticmethod
    async def login() -> dict: ...
    @staticmethod
    async def get_holdings() -> list: ...
    @staticmethod
    async def place_order(fund_code: str, amount: float) -> dict: ...
```

### TaskService（封装 TaskOrchestrator）

```python
# src/application/services/task_service.py
class TaskService:
    @staticmethod
    async def create_task(prompt: str, model: str = None) -> dict: ...
    @staticmethod
    async def get_task(task_id: str) -> dict: ...
    @staticmethod
    async def follow_up(task_id: str, message: str) -> dict: ...
```

## 2. 瘦化 router

逐个改造，从简单到复杂：

| 顺序 | Router | → AppService | 复杂度 |
|------|--------|-------------|--------|
| 1 | fund_query.py | QueryService | 低 |
| 2 | market.py | QueryService | 低 |
| 3 | strategy.py | QueryService | 低 |
| 4 | news.py | AggregationService | 低 |
| 5 | trade.py | TradeService | 中 |
| 6 | task.py + skill.py | TaskService | 中 |
| 7 | spy.py | 独立，不需要 AppService | 低 |
| 8 | terminal.py | 暂不动（WebSocket） | — |

改造模式：

```python
# 改造前
@router.get("/api/fund/{code}")
async def get_fund(code: str):
    client = get_ths_client()
    nav = await client.get_fund_nav(code)
    cached = fund_db.get_cache(code)
    return {"nav": nav, "cache": cached}

# 改造后
@router.get("/api/fund/{code}")
async def get_fund(code: str):
    return await QueryService.get_fund_snapshot(code)
```

## 3. 补全 common 模块

```python
# src/common/exceptions.py
class AppException(Exception):
    """应用异常基类"""
    def __init__(self, message: str, code: int = 400):
        self.message = message
        self.code = code

class NotFoundError(AppException):
    def __init__(self, message: str = "资源不存在"):
        super().__init__(message, 404)

class ExternalAPIError(AppException):
    def __init__(self, source: str, message: str):
        super().__init__(f"[{source}] {message}", 502)
```
