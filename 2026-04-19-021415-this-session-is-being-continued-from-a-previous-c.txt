● 搜到了关键信息。OAuth 转发方案不可行，原因：

  1. Anthropic 在 2026 年 2 月已明确禁止第三方使用订阅 OAuth token —
  用代理转发你的 Pro 订阅 token 违反 ToS，有封号风险
  2. OAuth token 只有 ~60 分钟有效期，刷新机制和本地 Claude Code 共享同一个
  refresh token — 如果 router 刷新了 token，你本地的 Claude Code 会失效（单
  refresh token 限制）
  3. 本地 Claude Code 发过来的 token 到 router 时可能已经过期

  所以 OAuth 这条路走不通。Router 的 Claude 
  路由需要一个独立的、服务端管理的认证方式，这才是正确的架构。

  现在的选项：

  1. Anthropic API Key — 官方方式，按 token 计费，比订阅贵

  3. 先不用 Claude 路由 — 把 plan-opus 也路由到 GLM 或其他可用模型
