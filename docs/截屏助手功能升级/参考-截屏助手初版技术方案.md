# 安卓截屏助手 App 技术方案

## 一、项目概述

### 1.1 项目目标
开发一款安卓截屏助手 App，具备悬浮窗交互、普通截屏、长截屏（滚动截屏）功能，支持客户端主动触发和服务端远程触发两种模式，实现截图 -> OCR 识别 -> LLM 处理 -> 结果反馈的完整链路。

### 1.2 核心场景

**场景一：服务端远程触发（自动化持仓采集）**
```
服务端下发指令 -> App 打开支付宝 -> 导航到基金持仓页面 -> 滚动长截屏 -> 发送到服务端 -> OCR + LLM 分析 -> 结果存储
```

**场景二：客户端主动触发（智能助手）**
```
用户点击悬浮窗 -> 截屏 -> 选择动作（如：识别聊天记录） -> 发送到服务端 -> OCR + LLM 处理 -> 返回推荐回复 -> 自动复制到剪贴板
```

```kotlin
class FloatingWindowService : Service() {
    private lateinit var windowManager: WindowManager
    private lateinit var floatingBall: View
    private var screenCaptureService: ScreenCaptureService? = null
    private var accessibilityService: MyAccessibilityService? = null

    override fun onCreate() {
        windowManager = getSystemService(WINDOW_SERVICE) as WindowManager

        // 创建悬浮球视图
        floatingBall = LayoutInflater.from(this).inflate(R.layout.floating_ball, null)

        val params = WindowManager.LayoutParams(
            WindowManager.LayoutParams.WRAP_CONTENT,
            WindowManager.LayoutParams.WRAP_CONTENT,
            WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
            WindowManager.LayoutParams.FLAG_NOT_FOCUSABLE,
            PixelFormat.TRANSLUCENT
        )

        // 悬浮球点击事件：弹出动作选择菜单
        floatingBall.setOnClickListener {
            showActionMenu()
        }

        // 悬浮球长按：展开设置菜单
        floatingBall.setOnLongClickListener {
            showSettingsMenu()
            true
        }

        windowManager.addView(floatingBall, params)
    }

    private fun showActionMenu() {
        // 启动动作选择界面
        val intent = Intent(this, ActionPickerActivity::class.java).apply {
            addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        }
        startActivity(intent)
    }

    // 执行截图（由 ActionPickerActivity 回调）
    fun executeCapture(action: ActionConfig, callback: (Bitmap) -> Unit) {
        // 1. 隐藏悬浮球
        floatingBall.visibility = View.INVISIBLE

        Handler(Looper.getMainLooper()).postDelayed({
            when (action.captureType) {
                CaptureType.NORMAL -> {
                    // 普通截屏
                    screenCaptureService?.captureScreen { bitmap ->
                        floatingBall.visibility = View.VISIBLE
                        callback(bitmap)
                    }
                }
                CaptureType.LONG_SCROLL -> {
                    // 长截屏（滚动拼接）
                    performLongCapture { bitmap ->
                        floatingBall.visibility = View.VISIBLE
                        callback(bitmap)
                    }
                }
            }
        }, 100)
    }

    private fun performLongCapture(callback: (Bitmap) -> Unit) {
        CoroutineScope(Dispatchers.Main).launch {
            val screenshots = mutableListOf<Bitmap>()
            var lastHash = ""

            repeat(10) { // 最多滚动 10 次
                // 截取当前屏幕
                val bitmap = screenCaptureService?.captureScreenSync() ?: return@repeat
                val hash = bitmap.contentHash()

                if (hash == lastHash) {
                    // 内容相同，已到底部
                    return@repeat
                }

                screenshots.add(bitmap)
                lastHash = hash

                // 执行滚动
                accessibilityService?.performScroll(ScrollDirection.DOWN)
                delay(500)
            }

            // 拼接所有截图
            val result = stitchScreenshots(screenshots)
            callback(result)
        }
    }
}

// 动作选择界面
class ActionPickerActivity : Activity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_action_picker)

        setupActionGrid()
    }

    private fun setupActionGrid() {
        val gridView = findViewById<GridView>(R.id.actionGrid)
        gridView.adapter = ActionAdapter(Actions.ALL)

        gridView.setOnItemClickListener { _, _, position, _ ->
            val action = Actions.ALL[position]
            executeAction(action)
        }

        findViewById<View>(R.id.btnCancel).setOnClickListener {
            finish()
        }
    }

    private fun executeAction(action: ActionConfig) {
        // 关闭菜单界面
        finish()

        // 显示进度提示
        showProgressNotification(action)

        // 请求 FloatingWindowService 执行截图
        FloatingWindowService.instance?.executeCapture(action) { bitmap ->
            // 发送到服务端
            sendToServer(action, bitmap)
        }
    }

    private fun sendToServer(action: ActionConfig, bitmap: Bitmap) {
        WebSocketClient.instance.sendScreenshot(bitmap, action.id) { result ->
            // 处理结果
            handleResult(action, result)
        }
    }

    private fun handleResult(action: ActionConfig, result: ServerResult) {
        when (action.id) {

            "ocr", "full_page" -> {
                copyToClipboard(result.data as String)

            }
            "fund_holdings" -> {
                // 显示分析结果
                showResultNotification("持仓分析完成", result.data as String)

        }
```

#### 3.1.2 截屏服务 (ScreenCaptureService)

**功能**：
- 普通截屏：捕获当前屏幕
- 长截屏：滚动页面并拼接多张截图

**技术方案**：

**A. 普通截屏 - MediaProjection API**
```kotlin
// 权限要求
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PROJECTION" />

class ScreenCaptureService : Service() {
    private var mediaProjection: MediaProjection? = null
    private var virtualDisplay: VirtualDisplay? = null
    private var imageReader: ImageReader? = null

    fun startCapture(resultCode: Int, data: Intent) {
        val mpManager = getSystemService(MEDIA_PROJECTION_SERVICE) as MediaProjectionManager
        mediaProjection = mpManager.getMediaProjection(resultCode, data)

        val metrics = resources.displayMetrics
        imageReader = ImageReader.newInstance(
            metrics.widthPixels,
            metrics.heightPixels,
            PixelFormat.RGBA_8888,
            2
        )

        virtualDisplay = mediaProjection?.createVirtualDisplay(
            "ScreenCapture",
            metrics.widthPixels, metrics.heightPixels, metrics.densityDpi,
            DisplayManager.VIRTUAL_DISPLAY_FLAG_AUTO_MIRROR,
            imageReader?.surface, null, null
        )
    }

    fun captureScreen(): Bitmap {
        val image = imageReader?.acquireLatestImage()
        // 转换为 Bitmap
        return convertImageToBitmap(image)
    }
}
```

```kotlin
implementation("com.squareup.okhttp3:okhttp:4.12.0")

class WebSocketClient(private val serverUrl: String) {
    private var webSocket: WebSocket? = null
    private val client = OkHttpClient.Builder()
        .readTimeout(0, TimeUnit.MILLISECONDS)  // 无超时
        .build()

    // 消息协议
    sealed class Message {
        // 客户端 -> 服务端
        data class Screenshot(
            val type: String = "screenshot",
            val imageBase64: String,
            val action: String,  // "ocr", "chat_reply", "fund_holdings"
            val timestamp: Long
        ) : Message()

        data class Status(
            val type: String = "status",
            val status: String,  // "ready", "busy", "error"
            val message: String
        ) : Message()

        // 服务端 -> 客户端
        data class Command(
            val type: String = "command",
            val action: String,  // "capture", "long_capture", "open_app", "scroll"
            val params: Map<String, Any>
        ) : Message()

        data class Result(
            val type: String = "result",
            val success: Boolean,
            val data: Any?,
            val message: String
        ) : Message()
    }

    fun connect() {
        val request = Request.Builder()
            .url(serverUrl)
            .build()

        webSocket = client.newWebSocket(request, object : WebSocketListener() {
            override fun onOpen(webSocket: WebSocket, response: Response) {
                sendStatus("ready", "Client connected")
            }

            override fun onMessage(webSocket: WebSocket, text: String) {
                val command = Gson().fromJson(text, Message.Command::class.java)
                handleCommand(command)
            }

            override fun onFailure(webSocket: WebSocket, t: Throwable, response: Response?) {
                // 重连逻辑
                reconnect()
            }
        })
    }

    private fun handleCommand(command: Message.Command) {
        when (command.action) {
            "capture" -> captureAndSend()
            "long_capture" -> longCaptureAndSend(command.params)
            "open_app" -> openApp(command.params["package"] as String)
            "scroll" -> performScroll(command.params)
            "click" -> performClick(command.params)
        }
    }

    fun sendScreenshot(bitmap: Bitmap, action: String) {
        val base64 = bitmapToBase64(bitmap)
        val message = Message.Screenshot(
            imageBase64 = base64,
            action = action,
            timestamp = System.currentTimeMillis()
        )
        webSocket?.send(Gson().toJson(message))
    }
```

```python
class ConnectionManager:
    def __init__(self):
        self.active_connections: Dict[str, WebSocket] = {}

    async def connect(self, client_id: str, websocket: WebSocket):
        await websocket.accept()
        self.active_connections[client_id] = websocket

    async def disconnect(self, client_id: str):
        if client_id in self.active_connections:
            del self.active_connections[client_id]

    async def send_command(self, client_id: str, command: dict):
        if client_id in self.active_connections:
            await self.active_connections[client_id].send_json(command)

    async def broadcast_command(self, command: dict):
        for websocket in self.active_connections.values():
            await websocket.send_json(command)

manager = ConnectionManager()

@app.websocket("/ws/{client_id}")
async def websocket_endpoint(websocket: WebSocket, client_id: str):
    await manager.connect(client_id, websocket)
    try:
        while True:
            data = await websocket.receive_json()
            await handle_message(client_id, data, websocket)
    except WebSocketDisconnect:
        await manager.disconnect(client_id)
```

### 5.1 图像拼接算法

**方案一：基于特征点匹配 (OpenCV)**
```python
import cv2
import numpy as np

def stitch_screenshots(images: list) -> np.ndarray:
    """使用 ORB 特征点匹配拼接截图"""
    result = images[0]

    for i in range(1, len(images)):
        img1 = result
        img2 = images[i]

        # 创建 ORB 检测器
        orb = cv2.ORB_create()

        # 检测关键点和描述符
        kp1, des1 = orb.detectAndCompute(img1, None)
        kp2, des2 = orb.detectAndCompute(img2, None)

        # 使用 BFMatcher 匹配
        bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
        matches = bf.match(des1, des2)
        matches = sorted(matches, key=lambda x: x.distance)

        # 计算偏移量
        if len(matches) > 10:
            src_pts = np.float32([kp1[m.queryIdx].pt for m in matches[:20]])
            dst_pts = np.float32([kp2[m.trainIdx].pt for m in matches[:20]])

            # 计算垂直偏移
            offset_y = int(np.median(src_pts[:, 1] - dst_pts[:, 1]))

            # 拼接
            result = np.vstack([
                img1[:offset_y + img1.shape[0] - img2.shape[0]],
                img2
            ])

    return result
```

**方案二：基于行像素匹配（适用于纯滚动场景）**
```kotlin
// Android 端实现
fun findOverlapRegion(bitmap1: Bitmap, bitmap2: Bitmap): Int {
    val height = bitmap1.height
    val width = bitmap1.width

    // 从 bitmap1 底部开始，寻找与 bitmap2 顶部匹配的行
    for (overlapHeight in (height * 0.1).toInt() .. (height * 0.4).toInt()) {
        var match = true
        for (y in 0 until 10) {  // 检查 10 行
            for (x in 0 until width step 10) {  // 每隔 10 像素采样
                val pixel1 = bitmap1.getPixel(x, height - overlapHeight + y)
                val pixel2 = bitmap2.getPixel(x, y)
                if (!pixelsSimilar(pixel1, pixel2)) {
                    match = false
                    break
                }
            }
            if (!match) break
        }
        if (match) return overlapHeight
    }
    return 0
}
```

## 八、技术风险与对策

| 风险 | 影响 | 对策 |
|-----|------|------|
| MediaProjection 需要用户授权 | 每次重启需要重新授权 | 使用前台服务保持，引导用户勾选"不再询问" |
| AccessibilityService 被系统杀死 | 自动化功能失效 | 加入 Foreground Service，电池优化白名单 |
| 不同 App 的 UI 差异 | 自动化点击失败 | 结合 OCR 动态识别元素位置，而非硬编码坐标 |
| 长截屏拼接错位 | 图片不完整 | 多种拼接算法备选，增加重叠区域 |
| WebSocket 断连 | 指令丢失 | 自动重连 + 指令队列 + 确认机制 |
| Android 版本兼容性 | 功能不可用 | 最低支持 API 26 (Android 8.0)，适配各版本 API |

| UI 框架 | Jetpack Compose | 声明式 UI，开发效率高 |
| 悬浮窗 | 传统 View | Compose 暂不支持 WindowManager |
| 异步处理 | Kotlin Coroutines + Flow | 替代 RxJava，更简洁 |
| 网络 | OkHttp | WebSocket + HTTP |
| 序列化 | Kotlinx Serialization | 官方方案，比 Gson 更 Kotlin 友好 |
| 图片加载 | Coil | Compose 原生支持 |
| 依赖注入 | Hilt | 可选，简化 Service/ViewModel 管理 |

**服务端（Python）**：
- 框架：FastAPI
- WebSocket：`websockets` / `starlette`
- OCR：GLM-OCR (已有)
- LLM：OpenAI / Claude API
