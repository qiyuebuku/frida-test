## 分析任务

请同时完成以下两大分析任务。

### A. 剧情结构分析

#### A1. major_events — 重大事件
筛选本段中最重要的事件（不是逐章罗列，而是筛出影响主线的大事件）。每个事件包含：
- `ch`: 章节编号（如 "ch0015"）
- `event`: 一句话描述
- `significance`: "high"（改变主线走向）或 "medium"（推进剧情但非关键转折）

#### A2. plot_lines_progress — 主线进展
识别本段中活跃的剧情主线（如修炼线、家族线、感情线、势力斗争线等）。每条包含：
- `name`: 主线名称（简洁，如"修炼突破"、"李家命运"）
- `status`: "introduced"（本段新出现）| "active"（持续推进）| "paused"（暂时搁置）| "resolved"（本段内完结）
- `start_ch`: 本段内该线首次出现的章节
- `progress`: 一句话描述本段内的进展
- `end_state`: 本段结束时的状态

#### A3. arc_candidates — 故事弧候选
识别本段中可能的故事弧（一个完整的小故事单元，有起因-发展-高潮-结局）。每个弧包含：
- `name`: 弧名称（如"李家起家弧"、"入门考验弧"）
- `start_ch`: 起始章节
- `end_ch`: 结束章节（如果本段内未结束，标注为本段最后一章并说明）
- `conflict`: 核心冲突（一句话）
- `turning_points`: 关键转折点数组（格式 "chXXXX: 描述"）
- `resolution`: 结局描述（未完结则写"未完结，延续至下一段"）

#### A4. foreshadowing — 伏笔追踪
- `planted`: 本段中新埋下的伏笔。每个包含 ch、content、importance（high/medium/low）
- `resolved`: 本段中回收的伏笔（可能是之前段落埋下的）。每个包含 planted_ch（埋下时的章节，如不在本段内可标"earlier"）、resolved_ch、content

#### A5. timeline_events — 时间线事件
提取本段中有明确时间标记的事件。每个包含：
- `ch`: 章节编号
- `time_marker`: 原文中的时间表述（如"三年后"、"十月初一"、"金丹期第五年"）
- `event`: 事件描述

### B. 世界观设定分类

对"世界观原始数据"中的设定条目以及你在章节摘要中发现的世界观信息进行分类、去重、标记首次出现章节。

#### B1. 分类

将每条设定归入以下 5 类之一：

- **power_system**：修炼等级体系、功法/心法、法术/神通、法宝的能力属性、灵气/灵力/修为等量化概念、特殊体质/血脉、丹药/材料的功能
  - **不包括**：法宝/灵器内部的可进入空间（归 geography）、组织的修炼传承制度（归 rules）
- **geography**：自然地名（山/河/湖/海/城）、人造建筑（宗门驻地/坊市/洞府）、**法宝/灵器内部的可进入空间**（如仙鉴内天地、须弥芥子空间）、秘境/幻境/试炼地、天地/界域/位面等空间概念
  - 核心判断：是否是一个**可以进入、有空间属性**的概念
- **factions**：有组织结构的团体（宗门/家族/帮派/盟会/国家）、临时联盟/敌对阵营
- **rules**：世界硬性法则（如天道限制、因果律）、修炼制度/传承规矩、社会规则/禁忌/习俗、经济/交易规则
- **misc**：无法归入以上类别的条目

#### 分类示例

| 条目 | 正确分类 | 常见错误 | 理由 |
|------|----------|----------|------|
| 日月同辉天地 | geography | ~~power_system~~ | 虽与修炼相关，但本质是一个**可进入的空间** |
| 仙鉴内天地 | geography | ~~power_system~~ | 法宝内部的独立空间 |
| 修仙六境 | power_system | | 修炼等级体系 |
| 太阴吐纳养轮经 | power_system | | 功法/心法 |
| 荫蔽制度 | rules | ~~factions~~ | 虽涉及宗门，但本质是一种**制度/规矩** |
| 月华元府 | factions | | 有组织结构的势力 |
| 望月湖 | geography | | 自然地名 |

#### B2. 去重
识别描述同一设定的不同条目，合并为一条（保留最完整的描述 + 所有出处章节）。

#### B3. 标记首次出现
每条设定标注 `first_chapter`（该设定首次揭示的章节编号）。

    "geography": [...],

    "rules": [...],

重要提示：
- 剧情分析和世界观分类是独立的两个任务，不要混淆
- 世界观分类中，每条设定的描述要完整、精确，不要过度概括
- **空间类设定一律归 geography**，即使它与修炼体系密切相关
- 如果一条设定跨类别，放入最主要的类别，并在描述中说明关联
- 结合章节摘要的完整上下文进行分类，不要仅依赖预提取数据
