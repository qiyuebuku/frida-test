# 书籍详情功能方案

> 日期：2026-02-06
> 状态：**已完成** ✓
> 前置依赖：搜索功能（已完成）

---

## 一、目标

通过搜索结果中的 `BookId`，获取书籍详情信息（书名、作者、简介、章节数、状态等），实现完整的 **搜索 → 书籍详情** 链路，100% 免 UI。

---

## 二、已确认的 API

### 2.1 书籍详情 API（核心）

| 项目 | 值 |
|------|---|
| endpoint | `GET /argus/api/v3/bookdetail/get` |
| 完整 URL | `https://druidv6.if.qidian.com/argus/api/v3/bookdetail/get?bookId={bookId}&isOutBook=0` |
| HTTP 方法 | GET |
| 参数 | `bookId`（必需），`isOutBook`（固定为 0） |
| 签名 | 由 OkHttpClient 拦截器自动处理 |

### 2.2 详情页打开时的所有 API

通过手动点击书籍进入详情页，捕获到以下 API 调用：

| API | 用途 |
|------|------|
| **`/argus/api/v3/bookdetail/get?bookId=xxx&isOutBook=0`** | **书籍完整详情（核心）** |
| `/argus/api/v3/bookdetail/lookfor?bookId=xxx&isOutBook=0` | 相关书籍推荐 |
| `/argus/api/v1/adv/getadvlist?position=...&bookId=xxx` | 广告（无用） |
| `/argus/api/v1/booklist/getrelation` | 书单关联 |
| `/argus/api/v1/dialog/get?positions=bookdetail_in&bookId=xxx` | 详情页弹窗 |
| `/argus/api/BookList/GetMyCreateBookListInBookDetail?id=xxx` | 用户书单 |

## 四、实现过程中的修复

### OkHttpClient 捕获逻辑优化

**问题**：`OkHttpClient.Builder.build()` hook 捕获的第一个客户端可能是非 API 客户端（如 Glide 图片加载），不带签名拦截器，导致 RPC 请求返回 HTTP 402 签名错误。

**修复**：改为从 `druidv6.if.qidian.com/argus` 域名的实际 API 请求中捕获 RealCall 的 client 字段，确保获取带签名拦截器的 API 客户端。使用 `apiClientCaptured` 标志避免重复更新。
