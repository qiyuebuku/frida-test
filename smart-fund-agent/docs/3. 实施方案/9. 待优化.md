# 待优化

### 普通图谱问答的上下文和耗时仍偏高（2026-07-29 记录）

**问题：** 当前一次标准查询已经限制为一次语义搜索、最多四张 Card、
一次 8 Card/8 Edge 的单跳展开和最多三条 Edge 精确打开，但真实 Codex
验收仍消耗约 3.36 万 Token、85 秒。主要剩余成本来自单跳展开返回的无关邻居，
以及 Codex 为筛选这些邻居产生的推理。

**最佳方案：** 在 `smart-fund-server` 增加面向两组候选 Card 的定向证据路径
检索接口，只返回连接两端的最短有效路径及必要 Edge handle；Agent 无需读取整个
一跳邻域。

**当前方案：** MCP 层通过字段投影删除调试元数据，并限制普通问答的工具预算。
该方案保持了证据完整性，真实问答质量合格，但尚未解决定向路径检索缺失的问题。

**整改条件：** 使用生产问题集完成至少 20 个 Codex Agent 用例评测，确认常见
问题的种子选择模式和目标路径长度后，在服务端设计并实现定向路径 API。

**优先级：** P1
