# 🧠 一、动态仓位的本质

不是简单调大调小，而是：

> ✅ **根据“你当前是否在优势局”来决定下注大小**

---

👉 两个核心输入：

```text
1. 系统胜率（你最近做得对不对）
2. 市场状态（现在是不是好行情）
```

---

# 🧩 二、整体模型（给你一个清晰结构）

```text
最终仓位 = 基础仓位 × 胜率因子 × 市场因子
```

---

👉 拆开看：

```text
base_position（来自score）
× winrate_factor（你最近状态）
× market_factor（市场环境）
```

---

# 🧮 三、胜率因子（你自己的“手感”）

---

## 📊 统计方式（滑动窗口）

```python
最近N笔交易（建议 N=5~10）
```

---

## 👉 计算：

```python
win_rate = 盈利次数 / N
avg_return = 平均收益
```

---

## 🎯 转换为因子（关键）

---

### ✅ 推荐函数（平滑版）

```python
def winrate_factor(win_rate):
    if win_rate >= 0.7:
        return 1.2
    elif win_rate >= 0.5:
        return 1.0
    elif win_rate >= 0.3:
        return 0.7
    else:
        return 0.5
```

---

👉 含义：

| 胜率   | 仓位 |
| ---- | -- |
| ≥70% | 放大 |
| 50%  | 正常 |
| <30% | 收缩 |

---

👉 本质：

> **你状态好 → 多做
> 状态差 → 少做**

---

# 📉 四、市场因子（外部环境）

---

## 📊 你需要 3 个指标：

---

### 1️⃣ 大盘趋势

```python
if 上证指数 > 5日均线:
    trend = 1
else:
    trend = 0
```

---

---

### 2️⃣ 市场情绪

```python
涨停数 / 跌停数
```

---

👉 转换：

```python
if ratio > 2:
    sentiment = 1.2
elif ratio > 1:
    sentiment = 1.0
else:
    sentiment = 0.7
```

---

---

### 3️⃣ 成交量

```python
if 今日成交量 > 5日均量:
    volume = 1.1
else:
    volume = 0.9
```

---

---

## 🎯 合成市场因子

```python
market_factor = (
    trend * 0.4 +
    sentiment * 0.4 +
    volume * 0.2
)
```

---

👉 简化版也可以：

```python
if 市场强:
    market_factor = 1.2
elif 市场一般:
    market_factor = 1.0
else:
    market_factor = 0.7
```

---

# ⚙️ 五、最终仓位计算

---

```python
final_position = base_position * winrate_factor * market_factor
```

---

👉 再加限制：

```python
final_position = min(final_position, 0.4)
```

---

---

## 📊 示例：

---

### 🟢 状态好 + 行情好

```text
base = 0.25
winrate = 1.2
market = 1.2

→ final = 0.36（重仓）
```

---

---

### 🔴 状态差 + 行情差

```text
base = 0.25
winrate = 0.5
market = 0.7

→ final = 0.087（轻仓）
```

---

👉 这就是核心价值：

> ❗**系统会自动“踩刹车”**
