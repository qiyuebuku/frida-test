## 目标

财联社是 A 股重要的中文资讯源。当前系统同时接入：

- `cls`：财联社电报，面向高频快讯。
- `cls_depth`：财联社深度，面向头条/深度文章列表。
- `cls_hot_article`：财联社热门文章榜单，按新文章 ID 获取结构化详情和完整正文。

## 客户端：CLSClient

**文件：** `src/infrastructure/clients/cls.py`
**运行验证：** `python -m src.infrastructure.clients.cls`

### 接口信息（已验证）

**财联社电报地址：** `https://www.cls.cn/v1/roll/get_roll_list`
**财联社深度地址：** `https://www.cls.cn/v3/depth/list/{depth_id}`
**财联社热门榜单地址：** `https://www.cls.cn/v2/article/hot/list`
**财联社文章详情地址：** `https://www.cls.cn/articles/v1/detail`
**方法：** GET
**认证方式：** 无登录态要求，但必须带 Web 端 `sign` 参数。

`sign` 生成规则：

1. 将请求参数按 key 排序；
2. 递归拼成 query-string；
3. 计算 `SHA1(query_string)`；
4. 对 SHA1 的十六进制字符串再计算 `MD5`。

| 参数 | 说明 |
|------|------|
| `app` | 固定 `CailianpressWeb` |
| `os` | 固定 `web` |
| `sv` | 固定 `8.7.9` |
| `rn` | 返回条数（默认 20，最大 50） |
| `refresh_type` | 固定 `1` |
| `last_time` | **增量游标**：传入上一页最后一条的 `ctime`，返回更早的数据 |
| `sign` | 按 Web 端规则生成的签名 |

### 返回字段

每条财联社电报包含以下关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 文章 ID |
| `title` | string | 标题 |
| `content` | string | 完整正文（快讯本身就短，content = brief） |
| `brief` | string | 摘要（与 content 基本相同） |
| `ctime` | int | 发布时间（Unix 时间戳） |
| `level` | string | 重要性：`"B"` = 重要，`"C"` = 普通 |
| `bold` | int | 是否加粗（1 = 重点新闻） |
| `reading_num` | int | 阅读量 |
| `subjects` | array | 主题标签：`[{subject_name, plate_id, ...}]` |
| `stock_list` | array | 关联个股：`[{name, StockID, RiseRange, last, ...}]` |
| `shareurl` | string | 分享链接 |
| `author` | string | 来源（如"新华社"、"央视新闻"） |

### 客户端方法

```python
# 基本采集：获取最新 N 条
items = await client.get_telegraph_list(rn=20)

# 翻页：获取 last_time 之前的数据
items = await client.get_telegraph_list(rn=20, last_time=1773804064)

# 增量采集：获取 since_ctime 之后的所有新数据（自动翻页）
new_items = await client.get_telegraph_since(since_ctime=1773804064)

# 财联社深度：获取头条/深度列表
items = await client.get_depth_list(depth_id=1000, rn=20)

# 财联社深度：增量获取 since_ctime 之后的新数据
new_items = await client.get_depth_since(depth_id=1000, since_ctime=1773804064)

# 财联社热门文章榜单
hot_items = await client.get_hot_article_list()

# 文章详情：支持数字 ID 或完整详情 URL，content 字段为正文 HTML
detail = await client.get_article_detail(2439549)
detail = await client.get_article_detail("https://www.cls.cn/detail/2439549")
```

热门文章的任务增量由 `NewsAggregator` 控制：`ft_collection_state.cursor.seen_ids`
保存已成功获取详情的文章 ID。每轮只请求榜单，新 ID 才调用详情接口；详情失败的
ID 不进入 checkpoint，下一轮继续重试。

### httpx 注意事项

| 问题 | 原因 | 解决 |
|------|------|------|
| 旧接口 404 | `/nodeapi/telegraphList` 已不可用 | 使用 `/v1/roll/get_roll_list` |
| 返回签名错误 | 缺少或错误计算 `sign` | 使用 `MD5(SHA1(sorted_query_string))` |
| 返回空内容 | 继承了 `BaseClient` 的同花顺 Referer | 覆盖 `__init__`，使用干净的 httpx 客户端 |
