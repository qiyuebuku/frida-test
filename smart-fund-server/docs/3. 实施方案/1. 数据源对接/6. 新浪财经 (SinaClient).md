## 方法清单

| 方法 | 数据 | 域名 |
|------|------|------|
| `get_stock_ranking(sort, count)` | 个股涨跌幅/成交量/换手率排行 | vip.stock.finance.sina.com.cn |
| `get_sector_ranking(sector_type, count)` | 板块涨跌排行（概念/行业） | money.finance.sina.com.cn |
| `get_realtime_quotes(symbols)` | A股实时行情（批量） | hq.sinajs.cn |
| `get_global_index(names?)` | 全球指数（道琼斯/纳斯达克/标普/恒生/台北） | hq.sinajs.cn |
| `get_forex(currencies?)` | 外汇（美元/欧元/日元/英镑/港币 vs 人民币） | hq.sinajs.cn |
| `get_futures(names?)` | 期货（黄金/铜/原油/白银/铁矿石） | hq.sinajs.cn |
| `get_kline(symbol, scale, datalen)` | K线数据（5/15/30/60/240分钟） | money.finance.sina.com.cn |
| `get_news(num, page)` | 财经新闻滚动 | feed.mix.sina.com.cn |
| `get_sector_money_flow(sector_type, count)` | 板块资金流（净流入/大中小单） | vip.stock.finance.sina.com.cn |
| `get_fund_nav(symbol, date_from?, date_to?)` | 基金净值（单位/累计） | stock.finance.sina.com.cn |

### 参数说明

**`get_stock_ranking`** 排序类型：rise(涨幅) / fall(跌幅) / volume(成交量) / turnover(成交额) / amplitude(振幅) / turnover_rate(换手率)

**`get_sector_ranking`** / **`get_sector_money_flow`** 板块类型：concept(概念) / industry(行业)

**`get_realtime_quotes`** 代码格式：`sh600519`/`sz000858`，纯数字自动补全前缀（6开头→sh，0/3开头→sz）

**`get_global_index`** 支持中文名称：道琼斯/纳斯达克/标普500/恒生指数/台湾加权，或代码 dji/nasdaq/sp500/hsi/twse

**`get_forex`** 支持中文：美元/欧元/日元/英镑/港币，或代码 usd/eur/jpy/gbp/hkd

**`get_futures`** 支持中文：黄金/铜/原油/白银/铁矿石，或代码 au/cu/sc/ag/i

**`get_kline`** scale 参数：5/15/30/60/240（分钟），240 = 日线
