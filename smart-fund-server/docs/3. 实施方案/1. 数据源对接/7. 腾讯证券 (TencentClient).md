## 方法清单

| 方法 | 数据 | 域名 |
|------|------|------|
| `get_stock_quote(codes)` | A股实时行情（含PE/PB/五档，批量20只） | web.sqt.gtimg.cn |
| `get_stock_batch_quote(codes)` | A股原始行情文本 | web.sqt.gtimg.cn |
| `get_stock_fund_flow(code, days?)` | 个股资金流向（今日+分钟趋势+5日+历史N日） | proxy.finance.qq.com |
| `get_minute_data(code)` | 个股分时数据（逐分钟 价格+量+额） | web.ifzq.gtimg.cn |
| `get_hk_quote(codes)` | 港股实时行情（批量，含PE/市值） | web.sqt.gtimg.cn |
| `get_us_quote(codes)` | 美股实时行情（批量，含PE/市值） | web.sqt.gtimg.cn |
| `get_intl_futures(names?)` | 国际期货（金/银/原油/天然气/铜/大豆/玉米/小麦） | qt.gtimg.cn |
| `get_stock_plates(code)` | 个股所属板块（行业+概念+地域，含涨跌幅） | proxy.finance.qq.com |
| `get_hot_stocks()` | 热门股排行（5分/1时/1日/1周） | proxy.finance.qq.com |
| `get_hk_us_kline(code, period, count)` | 港股/美股K线（日/周/月，前复权） | web.ifzq.gtimg.cn |
| `get_industry_rank(code)` | 个股行业内排名（PE/市值/EPS + 行业均值） | proxy.finance.qq.com |

### 参数说明

**`get_stock_fund_flow`** 返回：today（今日主力净流入）、minuteTrend（逐分钟）、fiveDayList（5日明细）、history（历史N日）

**`get_hk_quote`** 代码格式：`["00700", "09988", "01810"]`（自动加 `r_hk` 前缀）

**`get_us_quote`** 代码格式：`["AAPL", "MSFT", "NVDA"]`（自动加 `us` 前缀，去掉 `.OQ`）

**`get_intl_futures`** 支持中文：黄金/白银/原油/天然气/铜/大豆/玉米/小麦，或代码 gc/si/cl/ng/hg/s/c/w

**`get_hk_us_kline`** 代码须带前缀：`hk00700`（港股）、`usAAPL`（美股）；period: day/week/month
