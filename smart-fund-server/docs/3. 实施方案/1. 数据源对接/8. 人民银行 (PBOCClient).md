## 公告返回字段

所有公告方法返回统一格式：

```json
{
  "title": "公开市场业务交易公告 [2026]第53号",
  "url": "https://www.pbc.gov.cn/...",
  "published_at": "2026-03-20",
  "source": "pboc_omo",
  "source_name": "中国人民银行"
}
```

source 标签：`pboc`（新闻发布）/ `pboc_omo`（公开市场操作）/ `pboc_monetary`（货币政策）

## 公开市场操作公告（重点）

**采集频率：** 每个交易日上午发布（约 9:20）
**数据价值：** 每日逆回购操作金额+利率，直接反映央行流动性态度

公告正文示例：
> 2026年3月20日中国人民银行以固定利率、数量招标方式开展了205亿元7天期逆回购操作。
> 期限=7天, 操作利率=1.40%, 中标量=205亿元

**关键信号：**
- 逆回购净投放 > 0 → 央行向市场注入流动性
- 逆回购净回笼 > 0 → 央行回收流动性
- MLF 操作公告 → 中期流动性信号（每月约 1 次）
- 国债买卖公告 → 新工具，2025 年起启用

### 暂不实现的理由

1. **东方财富已覆盖核心指标**：M2/CPI/PPI/PMI/GDP 等宏观数据已通过 `EastmoneyClient.get_macro_*` 获取
2. **HTML 表格解析脆弱**：表格结构可能随年度变化，维护成本高
3. **作为事件源更高效**：社融超预期等信号通过新闻发布公告（已实现）即可感知
4. **后续如需实现**：URL 和数据格式已验证，可快速开发
