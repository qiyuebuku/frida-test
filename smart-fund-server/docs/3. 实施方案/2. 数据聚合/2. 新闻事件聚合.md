# 新闻事件聚合

**Service：** `src/domain/collection/services/news.py` → `NewsAggregator`
**Task 入口：** `src/interfaces/tasks/collection_tasks.py` → `collect_news`（队列 `collect_news`）
**CLI 入口：** `python -m src.interfaces.cli worker collect_news`
**优先级：** P0 — 决策信号的核心输入
**目标表：** ft_news
**状态管理：** ft_collection_state（通过 `python -m src.interfaces.cli init state` 初始化）

---

## 职责

从 11 个数据源采集新闻/快讯/深度文章/热门文章/公告/研报，统一格式后写入 `ft_news`。后续由知识图谱链路抽取认知卡片和高维主题索引。

### 关键能力

- **时间驱动回填**：首次启动自动回填历史数据（target_days 天），回填完成后切换增量模式
- **两阶段抓取**：回填时先快速翻列表页，每 5 页批量抓正文（比逐页抓快 3 倍）
- **触顶检测**：API 历史深度不足时自动检测并切换增量（空列表/游标无效/时间无进展）
- **fingerprint 预过滤**：已入库数据跳过正文抓取（避免缓存查询开销）
- **真实正文抓取**：多数源会并发请求详情页 URL；`cls` 电报自带短正文，`cls_hot_article` 仅对榜单新增 ID 请求结构化详情接口并保存完整正文
- **summary + content 双字段**：summary 是列表页摘要（短），content 是详情页正文（长，用于 AI 抽取）
- **跨源近似去重**：同一天内 title 相似度 > 0.85 的只保留最早一条（SequenceMatcher）
- **批次内 content 去重**：相同 content 不同标题的记录只保留一条
- **多部委并发**：政府网站采集时，7 个部委并发拉取（miit/miit_policy/ndrc/ndrc_notice/csrc/csrc_press/gov）
- **分布式锁 + 续锁**：防止多 worker 并发，回填时每 5 页自动续锁
- **网络重试**：超时/连接错误自动重试 3 次（间隔递增 2s/4s/6s）

| 请求类型 | 缓存 | TTL | 原因 |

## 采集模式

### 回填模式（mode = "backfill"）

首次初始化后自动进入。从最新数据向历史方向翻页，直到达到 target_time 或触顶。

```
tick() → _fetch_ths(cp) → _backfill_loop()
  page 1: 拉列表（with_content=False）  ← 快（~0.5s）
  page 2: 拉列表
  page 3: 拉列表
  page 4: 拉列表
  page 5: 拉列表
  → _flush_backfill_batch:
    fingerprint 预过滤（跳过已入库的） → 批量抓正文（仅新条目） → save → update checkpoint
  page 6-10: 同上
  → flush ...
  ...直到 oldest_time <= target_time 或触顶
```

### 触顶检测（3 个信号）

| 信号 | 含义 | checkpoint 标记 |
|------|------|----------------|
| 返回空列表 | API 无数据 | backfill_status = "ceiling" |
| 游标无效（next_cursor == -1 或不变） | API 明确告知到底 | backfill_status = "ceiling" |
| 时间无进展（秒级精度） | 翻页但数据不再变老 | backfill_status = "ceiling" |

### 增量模式（mode = "incremental"）

回填完成或触顶后自动切换。每次拉取 newest_time 之后的新数据。

| 源类型 | 增量方式 |
|--------|---------|
| CLS 电报 | `get_telegraph_since(newest_ctime)` — 服务端过滤 |
| CLS 深度 | `get_depth_since(newest_ctime)` — 游标翻页 + 本地时间过滤 |
| CLS 热门文章 | 拉榜单 → 与 `cursor.seen_ids` 比较 → 仅新增 ID 并发拉详情；失败 ID 下轮重试 |
| Gov/PBOC | `get_announcements_since(newest_date)` — 服务端过滤 |
| EM | `get_news_by_keyword_since(date)` — 本地过滤 |
| THS/Sina | 拉 page=1（不抓正文）→ 时间过滤 → 仅新条目抓正文 |
| 雪球 | 拉最新一页 → fingerprint 去重 |

## Checkpoint 格式（ft_collection_state）

```jsonc
{
  "mode": "backfill",               // "backfill" | "incremental"
  "target_time": "2026-02-11",      // 回填目标日期（now - target_days）
  "newest_time": "2026-04-12T15:30:00+08:00",  // 最新已采集时间
  "oldest_time": "2026-03-01T08:00:00+08:00",  // 最早已采集时间
  "cursor": 156,                    // 翻页游标；热门榜使用 {"seen_ids": [2439549, ...]}
  "backfill_status": "done",        // "done" | "ceiling" | 无此字段=进行中
  "max_trade_date": "2026-04-12T15:30:00+08:00"  // 兼容旧代码
}
```

## 统一输出格式

所有来源的新闻统一转换为以下格式后写入 `ft_news`：

```python
{
    "title": str,                      # 标题
    "summary": str,                    # 列表页摘要（快速预览用，短）
    "content": str,                    # 正文或列表摘要；cls_hot_article 保存详情完整正文
    "source": str,                     # 来源标识: cls/cls_depth/cls_hot_article/eastmoney/ths/sina/xueqiu/pboc/gov/miit/...
    "source_name": str,                # 来源中文名
    "source_reliability": float,       # 来源可靠性 0-1
    "category": str,                   # macro/industry/policy/company
    "url": str,                        # 原文链接
    "tags": list[str],                 # 关键词/标签
    "related_stocks": list[str],       # 关联股票代码
    "published_at": str,               # ISO 8601 时间
    "fingerprint": str,                # SHA256(title + source) 去重指纹
}
```

## 去重策略

| 层级 | 方法 | 时机 | 状态 |
|------|------|------|------|
| 同源精确去重 | `fingerprint = SHA256(title + source)` | 入库时 `ON CONFLICT DO NOTHING` | ✅ |
| 批次内 content 去重 | 同 content hash 只保留第一条 | `_save()` 入库前 | ✅ |
| 跨源近似去重 | 同一天内 title 相似度 > 0.85；`cls_hot_article` 为保留“进入热门榜”的来源语义而豁免 | `_save()` 入库前（SequenceMatcher） | ✅ |
