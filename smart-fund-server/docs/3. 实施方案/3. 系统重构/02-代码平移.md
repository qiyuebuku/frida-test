# Step 2：代码平移

**目标**：将现有代码按层归位到 `src/`，修正所有 import 路径。
**性质**：纯搬运，不改业务逻辑、不拆文件、不新增代码。
**风险**：低 — 只移文件 + 改 import。
**前置**：Step 1 完成（骨架已建）

---

## 1. 基础设施层（从底层开始）

| 源 | 目标 |
|----|------|
| `config.py` | `src/infrastructure/config/settings.py` |
| `services/clients/*` | `src/infrastructure/clients/` |
| `services/db/*` | `src/infrastructure/db/` |
| `services/tools/*` | `src/infrastructure/tools/` |

**import 替换**：
```
from config import ...          → from src.infrastructure.config.settings import ...
from services.clients...        → from src.infrastructure.clients...
from services.db...             → from src.infrastructure.db...
from services.tools...          → from src.infrastructure.tools...
```

> 根目录保留 `config.py` 兼容入口（`from src.infrastructure.config.settings import *`），Step 4 清理。

**移完后验证**：`python main.py` 正常启动。
