# 待优化

### 普通图谱研究缺少定向证据路径接口（2026-07-30 记录）

**问题：** 当前 Agent 需要先搜索 Card，再通过单跳展开寻找连接关系。邻居较多时
会把无关 Card 和 Edge 带入上下文，增加模型筛选成本。

**最佳方案：** 在 `smart-fund-server` 增加面向两组候选 Card 的定向证据路径
检索接口，只返回连接两端的最短有效路径及必要 Edge。

**当前方案：** Agent 限制首次打开的 Card 数量和单跳展开规模，只打开实际影响
结论的 Edge。该方案不影响证据真实性，但运行成本仍有优化空间。

**整改条件：** 使用生产问题集完成至少 20 个 OpenAI Agents SDK Runtime 用例
评测，确认种子选择模式和常用目标路径长度。

**优先级：** P1

### Langfuse OTLP Trace 写入返回 403（2026-07-30 记录）

**问题：** 当前 Langfuse 凭据可以通过认证检查，但 OpenTelemetry Trace 写入
接口返回 HTTP 403，导致 Agent Run 尚不能稳定显示在 Langfuse。

**最佳方案：** 修复 Langfuse 项目 Key、Host 或 OTLP ingestion 权限，使 Agents
SDK、模型轮次和 MCP 工具调用进入同一 Trace。

**当前方案：** Runtime 已完成 OpenInference 和 Langfuse 接线，并保留开关；
连接异常不会改变研究业务结果，但不能把观测链路视为已经验收通过。

**整改条件：** 获得可写入目标 Langfuse Project 的 OTLP 凭据并完成真实 Trace
验收。

**优先级：** P1
