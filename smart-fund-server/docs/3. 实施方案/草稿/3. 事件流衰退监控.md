# P1：事件流衰退监控

**优先级：** P1
**依赖：** ft_event_streams 有数据 + 新闻采集 + 资金流采集已运行
**产出：** 持仓关联的事件流衰退时产生"事件失效"止损信号

---

## 目标

买入基金后，持续追踪关联事件流的发酵/衰退状态。当事件流衰退时，产生止损信号。

---

```python
    3. 事件流 momentum：ft_event_streams.trend.momentum → decreasing 为衰退

```

### Step 2：配置定时调度

```python
# 盘中每小时 + 盘后（仅针对已持仓关联行业）
Schedule(scheduler_id="monitor_event_stream", queue="fund_event_monitor",
         cron_expression="0 10-14 * * 1-5", description="事件流衰退监控（盘中）")
Schedule(scheduler_id="monitor_event_stream_close", queue="fund_event_monitor",
         cron_expression="30 15 * * 1-5", description="事件流衰退监控（盘后）")
```
