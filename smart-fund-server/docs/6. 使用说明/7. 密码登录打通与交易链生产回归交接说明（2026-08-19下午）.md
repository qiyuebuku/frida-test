## 2. 密码登录根因与用法（核心知识）

**根因**：不是密码预处理——是 g6m builder 字段放错位。真机探针捕获证实
App 实际构造 `g6m.b=R(交易密码)`（线上 tag3，券商密码校验位）、
`g6m.c=S("")`（tag4 恒空）。旧代码 `S(密码)/R("0")` 让券商把 "0" 当密码
→ "[120047]客户交易密码错误"。

**登录线上 tag 布局**（s3s.b，buf 首字节 0x13）：
tag1=T("0") / tag2=N(资金账号) / **tag3=R(密码)** / tag4=S(空) /
tag5=Q(空) / tag6=U(yyb串"2393#16#1#1#")。密码明文，无任何加密
（getCommonPwd=记住密码取存储、tfm=安全键盘UI、w0s=改密码专用、
yjm RSA=查账号，全部排除，勿重复查）。

**login 端点用法**（`POST /stock/trade/login`，body 可组合）：
- `{}` — token 优先、过期自动密码 fallback、已登录短路
- `{"force":true}` — 绕过 already_logged_in 强制重登（被踢后恢复）
- `{"method":"pwd"}` — 跳过 token 直接密码登录（最强重建）
- `{"password":"..."}` — 一次性密码

实测：pwd 直登 21s / force 恢复 14ms / funds 1.8s。
密码存储：AVD `files/thshook_pwd.json`（775823，账号 9133857，券商川财 qsId=16）。
