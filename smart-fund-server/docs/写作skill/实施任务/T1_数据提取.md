## 输出

```
{output_dir}/
├── book_detail.md          # 书籍详情（作者、简介、标签、角色人气榜）
├── text/
│   ├── ch0001.md           # 纯正文（含评论数标注）
│   ├── ch0002.md
│   └── ...（正文章节数，随数据源变化）
└── reader/
    └── comments/
        ├── ch0001.md       # 结构化评论
        ├── ch0002.md
        └── ...（与 text/ 一一对应）
```

### 纯正文格式（`text/ch0001.md`）

```markdown
# 第一章 初入

陆江仙做了一个很长很长的梦，梦见田间种稻，梦见刀光剑影，梦见仙宗、女子、大湖。(18评)
"将《太阴吐纳练气诀》与《月华纪要秘旨》交出，我等可以只废去你修为。"(34评)
一道悦耳又冰冷的女声在耳边响起，陆江仙隐隐约约看见一张朦胧的脸庞，却什么也看不清楚。(11评)
……
"我不做人了？"(46评)
...
```

规则：
- 首行 `# {chapterName}`
- 空一行后逐段输出，段间无空行（节省 token）
- 有评论的段落末尾标注 `(N评)`（N 为 `--min-agree` 阈值以上的评论数），无评论的段落不标注
- 跳过 `isChapterReview` 的 item（章评不是正文）
- 不保留段落序号、元数据

### 结构化评论格式（`reader/comments/ch0001.md`）

```markdown
# 第一章 初入 · 评论

## 章评（12条）

**执仙齐天**（河南）· 2023-12-03 11:35 · 👍 1227
> 二刷三刷的不要剧透...

## 第1段评论（18条）

> 原文：陆江仙做了一个很长很长的梦，梦见田间种稻，梦见刀光剑影，梦见仙宗、女子、大湖。

**执仙齐天**（河南）· 2023-12-03 11:37 · 👍 2847
> 多刷的不要剧透...

## 第2段评论（34条）

> 原文："将《太阴吐纳练气诀》与《月华纪要秘旨》交出，我等可以只废去你修为。"

**老书虫2021**（重庆）· 2023-01-02 17:28 · 👍 6039
> 这些话好傻，这谁还交出来
```

规则：
- 章评区：`## 章评（N条）`
- 段评区：`## 第{index}段评论（N条）`，每段前引用原文 `> 原文：{text}`
- 评论格式复用现有 `comment_to_markdown()` 函数（含回复关系、图片链接等）
- 按 `--min-agree` 阈值过滤评论（默认 15），同时保留有高赞回复的低赞评论及被引用的上下文评论
- 原文引用截取前 100 字，超出部分以 `...` 结尾
- 无评论的段落不出现在评论文件中
- 整章无评论时生成空文件（只有标题）

## 正文/非正文判断

852 个 JSON 文件中（不含 `_book_detail.json`），章节名有四种格式需要识别为正文：

| 格式 | 示例 | 数量 |
|------|------|------|
| 标准 `第X章 标题` | "第一章 初入" | 802 |
| 缺空格 `第X章标题` | "第一百二十六章布阵与婚约" | 2 |
| 缺"章"字 `第X 标题` | "第二十四 归宗" | 5 |
| 缺"第"字 `X章 标题` | "五百三十二章 动乱" | 3 |

判断正则：`r'^第.+章[\s\S]|^第[\d一二三四五六七八九十百千]+\s|^[\d一二三四五六七八九十百千]+章[\s\S]'`

> 注：使用 `[\s\S]` 而非 `\s`，兼容"章"后直接跟标题无空格的情况。

其余 40 个为非正文（版权信息、感谢、请假、卷终、感想、番外等）。
非正文文件跳过，不生成 text/ 和 comments/ 文件。

---

## 章节编号

正文文件按文件名排序后**顺序编号**：ch0001、ch0002、...

不使用原始文件名中的序号（如 `0015`），也不使用 chapterName 中的章节号（如"第一章"），因为：
- 原始序号包含非正文的占位
- chapterName 中的章节号有不规范情况

顺序编号最简单，且与知识库内部引用一致（`ch0001` 始终是第一个正文章节）。

## 实现概要

新增 4 个函数：

| 函数 | 职责 |
|------|------|
| `is_chapter_file(data)` | 用正则判断 chapterName 是否为正文章节 |
| `extract_text(data)` | 提取纯正文 Markdown（跳过 `isChapterReview` 段落） |
| `extract_comments(data, min_agree)` | 提取结构化评论（复用 `comment_to_markdown()` + `show_comment_ids` 过滤机制） |
| `process_kb_mode(input_dir, output_dir, min_agree)` | 主流程：扫描 → 过滤 → 编号 → 生成 text/ 和 reader/comments/ |

argparse 新增 `--mode kb`，默认输出目录 `qidian/novel_kb/玄鉴仙族/`。

## 命令

```bash
# 执行
python process_chapters.py --mode kb \
  --input output/1035420986_玄鉴仙族_cleaned \
  --output ../novel_kb/玄鉴仙族 \
  --min-agree 15

# 验证
ls ../novel_kb/玄鉴仙族/text/ | wc -l        # 应与正文章节数一致
ls ../novel_kb/玄鉴仙族/reader/comments/ | wc -l  # 应与 text/ 一一对应
head -20 ../novel_kb/玄鉴仙族/text/ch0001.md
head -30 ../novel_kb/玄鉴仙族/reader/comments/ch0001.md
```

## 验收标准

1. ✅ `text/` 文件数与正文章节数一致，每个只含标题 + 正文段落 + 评论数标注
2. ✅ `reader/comments/` 与 `text/` 一一对应，每段评论前有 `> 原文：` 引用
3. ✅ 非正文文件均被跳过
4. ✅ 评论按 min-agree=15 过滤
5. ✅ 章节编号连续（ch0001 ~ ch{N:04d}）
6. ✅ `book_detail.md` 包含作者、简介、标签、角色人气榜
