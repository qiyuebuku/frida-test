# T7：风格层分析

> 状态：✅ 已完成

## 目标

分析原文写作风格，生成结构化风格参考（`style/narrative.md` + `style/vocabulary.md` + `style/rhythm.md` + `style/index.md`），让续写 AI 能精确复制原作的"手感"。

风格层是决定续写"像不像原作"的关键。很多续写在剧情和设定上没问题，但一读就觉得不对——问题就出在风格层。

## 核心难题（4 大挑战）

### 1. 定量分析 vs 定性分析的平衡

风格分析需要**两类信息**：
- **定量**：句长分布、对话比例、段落长度、场景切换频率——这些 Python 可以精确统计
- **定性**：叙事视角、意象偏好、情感表达方式、文风标签——这些需要 Claude 语义理解

设计思路：**Python 负责全量统计（0 次调用），Claude 负责抽样语义分析（少量调用）**。

### 2. 抽样代表性

901 章不可能全部分析。但不同阶段的写作风格可能有差异（作者成长、剧情节奏变化）。需要设计合理的抽样策略，确保前期/中期/后期都有覆盖。

### 3. 风格演化捕捉

长篇小说的风格不是静态的。作者在第 1 章和第 900 章的写作水平、节奏把控可能完全不同。需要区分"稳定风格特征"（贯穿全书）和"演化趋势"（随章节变化）。

### 4. 风格特征的可操作性

风格分析的最终目的是**指导续写**。单纯的统计数据（如"平均句长 18.5 字"）对 AI 用处不大。需要转化为**可操作的写作指令**（如"战斗场景偏好 <10 字短句连发，日常场景使用 20-30 字长句"）。

## 三阶段 Pipeline 设计

### 阶段 0：Python 全量统计 + 辅助数据解析（0 次 Claude 调用）

分三部分：A. 全量定量统计，B. T3 弧信息解析，C. T6 读者反馈解析。

#### A. 全量定量统计

对全部 901 章纯正文执行定量分析。

#### 统计项

| 类别 | 统计项 | 方法 |
|------|--------|------|
| **句长** | 平均句长、中位数、标准差 | 按句号/问号/叹号/省略号分句 |
| **句长分布** | 短句(<10字)、中句(10-30字)、长句(>30字)占比 | 同上 |
| **段落** | 平均段落长度、最长/最短段落 | 按段落分割 |
| **对话** | 对话行数占比、平均对话长度 | 检测引号 `「」""''` |
| **场景切换** | 每章平均场景数、切换标记 | 检测空行/分隔符/视角转换 |
| **章首模式** | 前 3 句的类型分布（环境/动作/对话/心理） | 正则分类 |
| **章尾模式** | 末 3 句的类型分布（悬念/收束/对话） | 正则分类 |
| **高频词** | 出现频率 Top 100 | jieba 分词 + 词频统计 |
| **对话标签** | "说"/"道"/"笑道"等对话引导词频率 | 正则匹配 |
| **时间表达** | 传统时辰 vs 现代时间 | 正则匹配 |
| **情感表达** | 直白情感词 vs 动作/细节暗示 | 关键词列表匹配 |

#### 分段统计

**双重分段**，提供两种粒度的风格对比：

1. **按弧分段**（精细，来自 T3）：解析 `plot/outline/arc_*.md` 中的章节范围，按每个弧分别统计。不同弧的情感基调不同（日常弧 vs 战斗弧），风格差异更有结构意义。
2. **按时段分段**（粗粒度，兜底）：前期 ch0001~ch0300 / 中期 ch0301~ch0600 / 后期 ch0601~ch0901。如果 T3 弧文件不存在则使用此方案。

#### B. T3 弧信息解析

从 `plot/outline/` 目录解析弧文件：

```python
# 解析每个 arc_XX.md
arc_info = {
    "arc_id": "arc_01",
    "chapter_range": ["ch0001", "ch0003"],  # 从标题行解析
    "core_conflict": "陆江仙残魂附身铜镜...",  # 核心冲突

    "turning_points": ["ch0001", "ch0003"],   # 关键转折点章节

```

**用途**：
- `chapter_range` → 按弧分段统计
- `turning_points` → 优先抽样（转折章的写法最有特色）
- `mood` → 分析不同氛围下的风格差异

### 阶段 1：Claude 抽样精析（~5-8 次调用）

#### 智能抽样策略

从 901 章中抽取 **15-30 章**进行深度分析。抽样遵循三重优先级：

**优先级 1：必选章**（~5 章）
- 第 1 章（开篇风格基线）
- 最后一章（续写直接衔接点）
- T6 高赞 TOP 3 章节（读者验证的风格标杆）

**优先级 2：转折章**（~5-10 章，来自 T3 弧文件）
- 每个弧的关键转折点章节
- 转折处的写法最有特色（情感高峰、节奏变化）

**优先级 3：均匀补充**（~5-15 章）
- 确保每个弧至少有 1 章被抽到
- 对弧内未被优先级 1/2 覆盖的区间做均匀补充

每次调用分析 3-5 章原文（每章约 6K 字，3-5 章 = 18K~30K 字输入），提取定性特征。

#### Claude 分析维度

每次调用要求 Claude 从原文中提取 **7 个维度**（前 6 个为基础维度，第 7 个为读者验证维度）：

1. **叙事视角**：第几人称、是否切换、视角切换时机
2. **场景描写偏好**：环境描写详略、动作描写风格、心理描写方式
3. **情感表达技巧**：是否克制、用什么手法替代直白表达
4. **意象/修辞**：常用比喻、意象、修辞手法及典型例句
5. **用词习惯**：偏好词汇、口语化程度、古典/现代比例
6. **写作技巧标注**：具体到段落级别的技巧示例（含原文引用）
7. **读者验证分析**（当本批包含高赞段落时）：分析高赞段落**为什么成功**——用了什么具体写法触发了读者情绪？这个写法可以如何复用？

### 阶段 2：全局融合（1 次调用）

合并三大信息源，生成 4 个产出文件。

#### 输入

- `stats.json`：全量统计数据（含按弧分段统计 + 读者反馈解析结果）
- `sample_analysis_*.json`：所有抽样分析结果（含读者验证维度）
- `sampling_plan.json`：抽样计划（含弧信息 + 高赞段落列表）
- 弧级风格对比数据（不同弧的统计差异 → 识别"战斗弧更短句"等模式）
- 读者高赞段落的成功写法汇总（来自阶段 1 的 `reader_validated` 字段）

#### 融合重点

Claude 在融合时需要特别关注：
1. **统计 + 语义的交叉验证**：如 Python 统计"短句占比 35%"，Claude 分析"战斗场景偏好短句"→ 融合为"战斗场景短句率 XX%，日常场景 XX%"
2. **弧级风格差异**：如果不同弧的统计有显著差异（句长标准差 >3），在产出中标注"XX 类弧的风格特征"
3. **读者验证的技巧优先级**：高赞段落中使用的写作技巧应在"写作指导"中**优先推荐**

#### 输出

使用 Write 工具直接生成：
- `style/narrative.md`
- `style/vocabulary.md`
- `style/rhythm.md`
- `style/index.md`（Python 生成）

## 关键设计决策

### 为什么用抽样而非全量分析？

1. **风格具有统计稳定性**：作者的写作风格在 30 章样本中就能充分体现
2. **全量分析成本高收益低**：901 章 × 6K 字 ≈ 540 万字，全部交给 Claude 需要 ~50 次调用
3. **Python 统计已覆盖全量**：句长、对话比例等定量指标 Python 已做全量统计
4. **Claude 只做定性分析**：叙事技巧、情感表达等需要语义理解的部分才用 Claude

### 为什么不用 jieba 以外的分词工具？

jieba 是最轻量的选择，不需要额外安装大型模型。风格分析只需要词频统计和基础分词，jieba 足够。**jieba 是必须依赖**，脚本启动时检查 `import jieba`，未安装则报错退出：`ERROR: 请先安装 jieba（pip install jieba）`。

### 为什么阶段 1 每次分析 3-5 章？

- 单章 ~6K 字，3-5 章 = 18K~30K 字
- 加上 prompt + 输出，总 token < 50K
- 多章对比可以发现风格的一致性和变化
- 太少（1 章）缺乏对比，太多（10 章）输入过长

### 风格演化如何处理？

- Python 统计提供**双重分段**：按弧分段（精细）+ 按时段分段（粗粒度兜底）
- Claude 分析按弧智能抽样，确保不同弧类型都有覆盖
- 最终产出中每个维度都有"风格演化"和"弧级差异"小节
- **续写时以后期风格为准**（因为续写接在最后一章之后）
- **弧级差异用于场景匹配**：续写战斗场景时参照战斗弧风格，日常场景参照日常弧风格

### 为什么 T3 弧文件和 T6 读者反馈是必须依赖？

1. **T3 弧文件的价值**：简单的"前/中/后"三分法忽略了故事结构。同一时期内，日常弧和战斗弧的风格可能完全不同。按弧分段能发现这种**场景驱动的风格差异**——这是风格分析精确度的关键。
2. **T6 读者反馈的价值**：风格分析的终极目的是指导续写，而读者反馈是唯一的"市场验证"信号。高赞段落 = 读者认可的风格标杆，这些段落使用的写作技巧应该被**优先学习和复用**。没有这个维度，风格分析只是"统计报告"而非"写作指南"。
3. **不做降级**：T3 和 T6 是保证分析精度的核心数据源，缺失会严重影响产出质量。脚本启动时前置检查，缺失则报错退出。

## 与早期风格学习系统的关系

项目早期曾开发过基于 `core/style_learning_system.py` 的风格学习系统，提炼出 6 大核心写作技巧：
1. 克制情感表达
2. 传统时辰
3. 细节暗示
4. 视觉反差
5. 口语化
6. 信息密度

- 但 T7 不预设任何特定技巧，由 Claude 从原文中自主发现
