# 同花顺基金账户登录逆向分析报告

## 概述

通过 Frida Hook 捕获到了完整的基金交易账户登录流程，发现这是一个完全独立于同花顺App账号的认证系统。

## 一、登录接口

### 1.1 基本信息

- **URL**: `https://trade.5ifund.com/rz/account/login/noauth/v1/result/safe/check`
- **Method**: `POST`
- **Content-Type**: `application/x-www-form-urlencoded`

### 1.2 请求Headers

```
token: -1
custId: -1
User-Agent: Hexin_Gphone/11.48.03 (Royal Flush) innerversion/G037.08.194.1.32 hxtheme/0 GphoneIjiJinSDK/V7.39.01 ifOperator/145
Client-Referer:
source: SDK
Content-Type: application/x-www-form-urlencoded
Host: trade.5ifund.com
Connection: Keep-Alive
Accept-Encoding: gzip
```

### 1.3 请求参数 (Form-Encoded)

| 参数 | 示例值 | 说明 |
|------|--------|------|
| key1 | 7246091a5f126b63 | 设备ID |
| uId | 7246091a5f126b63 | 用户ID (与key1相同) |
| key2 | 2293a78f6581c12bbb334759458d4de3 | 设备签名 |
| password | DB53EF5F124897EA9DD2C33DE1566592 | **密码MD5值** |
| ipAddress | null | IP地址 (可为null) |
| thsUserId | 690359103 | 同花顺用户ID |
| device | OnePlus%20PLQ110 | 设备型号 |
| deviceName | OnePlus%20 | 设备名称 |
| account | 100113970166 | **基金账号** |
| loginSource | SDK | 登录来源 |
| operator | 145 | 运营商代码 |

## 二、密码加密机制

### 2.1 密码加密流程

1. **原始密码** → MD5 哈希 → `DB53EF5F124897EA9DD2C33DE1566592`
2. 该MD5值直接作为 `password` 参数提交

### 2.2 密码二次加密（传输加密）

虽然提交时用的是MD5，但在某些场景下还会对密码进行AES加密：

```
Algorithm: AES/CBC/PKCS5Padding
Input: DB53EF5F124897EA9DD2C33DE1566592
Output (base64): 4R3QT8o9wlpjGVuBJE7QTHMYBSx3dSseEe/pISzxQfuSBqhnX4KwA7FqOOABCP8V
```

## 三、认证Token (key5)

### 3.1 key5 结构

key5 是一个 JWT 格式的 token，格式为：`{header_base64}.{payload_base64}`


### 3.2 key5 Payload 解码

Base64 解码第一部分得到：
```json
{
  "cId": "100113970166",      // 客户ID (custId)
  "exp": 1775362511939,        // 过期时间戳(毫秒) ≈ 2026-04-01 (约1个月)
  "sou": "SDK",                // 来源
  "type": "PWD",               // 认证类型 (密码登录)
  "v": "1.0"                   // 版本
}
```

### 3.3 key5 使用场景

登录成功后，所有业务请求都需要携带 key3、key4、key5：

```
https://trade.5ifund.com/rs/incomequery/queryzcsharemobilehomenine/100113970166?key1=xxx&key2=xxx&key5=xxx&key3=100113970166&key4=auth
```

## 六、Token 刷新机制推测

### 6.1 当前问题

- key5 有效期约30天，过期后需要重新登录
- 原始密码未知（只有MD5值）

### 6.2 可能的刷新方式

#### 方案A: 使用密码MD5重新登录 ✅ **推荐**

```python
def refresh_token(account, password_md5, device_id, key2):
    """使用密码MD5重新登录获取新token"""
    url = "https://trade.5ifund.com/rz/account/login/noauth/v1/result/safe/check"

    data = {
        "key1": device_id,
        "uId": device_id,
        "key2": key2,
        "password": password_md5,  # 直接使用MD5
        "ipAddress": "null",
        "thsUserId": "690359103",  # 可能需要动态获取
        "device": "OnePlus PLQ110",
        "deviceName": "OnePlus ",
        "account": account,
        "loginSource": "SDK",
        "operator": "145"
    }

    headers = {
        "token": "-1",
        "custId": "-1",
        "source": "SDK",
        "Content-Type": "application/x-www-form-urlencoded",
        "User-Agent": "Hexin_Gphone/11.48.03 (Royal Flush) innerversion/G037.08.194.1.32 hxtheme/0 GphoneIjiJinSDK/V7.39.01 ifOperator/145"
    }

    response = requests.post(url, data=data, headers=headers)
    result = response.json()

    return result["key5"], result["key3"], result["key4"]
```

## 八、关键发现

1. ✅ **基金账户登录不需要手机短信验证**，只需账号+密码
2. ✅ **密码使用MD5存储**，无需明文密码即可登录
3. ✅ **key5是标准JWT token**，包含过期时间和客户信息
4. ✅ **完全独立的认证系统**，与同花顺App账号无关
5. ⚠️ **需要保存password_md5** 以实现自动刷新

## 九、安全建议

1. **加密存储** `password_md5`：虽然是MD5，但仍需加密存储
2. **本地生成** `key1` 和 `key2`：避免频繁变化导致风控
3. **监控token过期时间**：提前刷新避免服务中断
4. **限制API调用频率**：避免触发风控
